## 4. 问题分析

### Q1：主轴及塔架疲劳损伤程度量化指标计算低复杂度模型

**题目要求**
- 建立数学模型，实现两种元件（主轴、塔架）**任意时段**累积疲劳损伤的**实时计算**
- **不得使用机器学习方法**
- 测试环境基于 **CPU**，计算时间 **< 1.00s**（100 台风机 × 200 件元件）
- 计算结果需正确反映累积疲劳损伤程度，并**展示与雨流计数法结果的相似程度**（趋势一致即可，不必相等）
- 输出：附件5 表格（100s 内 100 台×200 件**每秒**损伤值，初值可从 0 起）
- 展示：选取 5~10 个代表性样本，用图展示 0~100s 累积损伤增长过程，说明方法对全部样本有效

**输入 / 输出**
- 输入：载荷时序（塔架推力、主轴扭矩），采样间隔 1s
- 输出：单位时间（每秒）损伤增量 $\Delta D$，及累积值 $D(t)$

**核心难点（本题最见功底处）**
1. **经典雨流计数法无法在线** —— 题目明确说明，必须设计替代算法
2. **周期特征不标准** —— 波峰波谷不易辨识，不能简单数峰
3. **速度约束极严** —— 200 件元件 × 100s，单件要在毫秒级完成

**候选建模路线（三条，待门禁 A 定夺）**

| 路线 | 思路 | 优点 | 风险 |
|:--|:--|:--|:--|
| **① 滑动窗口 + 峰谷对近似** | 对每台风机的载荷序列做在线滑动窗口，提取局部极值对 → 幅值 → S-N 积分 | 复杂度 O(n)，物理意义清晰 | 近似误差需证明与雨流趋势一致 |
| **② 短时傅里叶/谱法** | 把载荷序列视作窄带随机过程，用**功率谱密度**估应力幅值分布（Dirlik / 瑞利近似） | 计算极快，频域天然适合实时 | 依赖平稳性假设，题面说周期不标准 |
| **③ 等效损伤速率法** | 不逐循环计数，直接建立"载荷统计量 → 损伤速率"的经验映射 | 最快 | 接近"拟合"，需防被判为数据驱动 |

**建议倾向：路线 ① 为主，用 ② 做交叉验证**（符合 skill 的"方法互验"要求，关键数值至少 3 种独立方法）。

**验证方案**
- 与附件1 的**雨流结果对比**：至少给**趋势一致性**指标（如逐时刻损伤比值的中位数、Spearman 秩相关、相对误差分布）
- **速度实测**：报告 100 台×200 元件总耗时，与 1.00s 门限对比
- **方法互验**：①与②互差入表

**计划图表**
- 0~100s 累积损伤增长曲线（5~10 个代表性样本）
- 本方法 vs 雨流结果的散点/对比图
- 耗时柱状图（含 1.00s 门限线）

### Q2：利用风速及功率估算塔架推力和主轴扭矩

**题目要求**
- 建立模型，根据风机所处位置**风速** `Vwi` 和**功率参考值** `Prefi`，估算**轴系扭矩** `Tsi` 与**塔顶推力** `Fti`
- 可结合受力分析、能量守恒或任意合理思路
- **数据量较少，不建议使用机器学习**
- 输出：附件6 表格（100 台全部时刻的应力/扭矩）
- 需统计**全部时刻估算值与参照值之差的平方和**

**输入 / 输出**
- 输入：$V_{wi}$、$P_{ref,i}$
- 输出：$T_{si}$、$F_{ti}$

**核心机理（题面给出的物理线索）**
- 题面指明：**本题数据均为风能过剩情形**（风速超过额定风速 11.2 m/s）
- 风速恰好使功率达标时，推力/扭矩最小；风速过高，多余风能部分转化为**主轴扭矩**和**塔架推力**
- 因此：$T_{si}, F_{ti}$ 主要来自 **"风能过剩量"** 与转速不匹配

**候选建模路线**

| 路线 | 思路 | 优点 |
|:--|:--|:--|
| **① 空气动力学机理式** | 由叶素动量理论/推力系数 $C_T$、转矩系数 $C_Q$ 出发，推 $F_t=\frac12\rho A C_T V^2$、$T=\frac{P}{\omega}$ | 物理可解释，符合"受力分析"要求 |
| **② 能量守恒 + 转速不匹配** | 风能输入 − 输出功率 = 多余部分 → 按比例分配为推力/扭矩 | 简单，易解释 |
| **③ 无量纲相似 + 拟合** | 构造无量纲量（如 $T/(\rho V^2 R)$）与功率系数关系，用少量数据拟合幂律 | 兼顾机理与数据 |

**建议：路线 ①（形式）+ ③（参数标定）**。即：以机理式确定函数形式（$F \propto V^2$、$T$ 与 $P/\omega$ 相关），用附件2 的参照值**标定系数**，再报平方和。

**⚠️ 高风险点（门禁 A 必问）**
- 题面说"**估算**"并要与"**参考值**对比" —— 那**参考值从哪来**？是附件2 里直接给了 $T_s, F_t$？
- 若给了 → 这就是**拟合/标定**任务，需注意**过拟合风险**，须做留出验证
- 若没给 → 需从附件1 的载荷数据反推，那 Q1 与 Q2 的数据链路要打通

**验证方案**
- **残差分析** + **留出集验证**（防止用全量数据标定后自我循环）
- 报**平方和**（题目明确要求），另报 RMSE、相对误差
- 量纲与量级检查（$F$ 应在 MN 量级、$T$ 应在 MN·m 量级）

### Q3：有功调度优化问题构建与实时求解

**题目要求**
- 每秒一次功率分配计算（**实时性硬要求**）
- **优化目标**：尽可能降低场站所有风机**总体疲劳损伤**，需**分别**将主轴和塔架两种元件定义为**两个目标**（自行定义，需合理且可解释，如:各元件损伤**平均值最小**，或**损伤最严重元件**的值最小）
- **约束条件**：
  1. $\sum_i P_{ref,i} = P_t$（功率平衡）
  2. $0 \le P_{ref,i} \le 5$ MW（额定上限）
  3. $|P_{ref,i} - P_t/W_t| \le 1$ MW（**与平均分配偏差不超过 1MW**，保证原控制器适用）
- 给出**目标函数 + 权重设计思路**并说明
- 需提供**带计时器的动图**展示实时性
- 需展示约束满足情况，及优化前后对比：各风机累积损伤、损伤总和、**参考功率方差**

**决策变量 / 目标**
- 决策变量：$P_{ref,i}$（$i=1..100$）
- 双目标：$\min \bar{D}_{shaft}(P)$、$\min \bar{D}_{tower}(P)$（或 max 形式）

**核心难点**
1. **高维**（100 维）+ **每秒求解** → 梯度类/启发式都可能太慢，需利用结构
2. **双目标** → 需要权重设计或 Pareto 思路，且要**给出可解释的权重**
3. **目标函数非线性** → 损伤是 $P_{ref}$ 的隐函数（$P_{ref} \to V, \omega \to T, F \to S \to N_F \to D$），链式求导复杂

**候选建模路线**

| 路线 | 思路 | 适用性 |
|:--|:--|:--|
| **① 梯度投影法** | 目标可微，用解析/数值梯度 + 投影保证约束 | 快，适合实时 |
| **② 序列二次规划 (SQP)/内点法** | 每步解小规模 QP | 稳定，但 100 维每步可能超时 |
| **③ 解析化 + 凸近似** | 若能把损伤近似成 $P$ 的二次型，直接解得闭式/一次投影 | **最快**，最适合每秒求解 |
| **④ 启发式（PSO/GA）** | 简单但**慢**，不适合每秒 | 仅作离线对比基准 |

**建议：优先探 ③（凸近似 + 解析），失败退 ①**。④ 只作为"优化前 vs 优化后"的对照基线。

**验证方案**（优化类标准：可行性 + 基线比较 + 扰动稳定性）
- **约束可行性**：逐时刻检查三条约束的残差（尤其 1MW 偏差约束）
- **基线对比**：与平均分配法比损伤总和、方差
- **扰动稳定性**：对权重、初值做扰动，看最优解是否稳定
- **计时**：每秒优化耗时的分布（中位数/95分位）

**计划图表**
- 优化前后各风机损伤分布对比
- 损伤总和/方差随时间曲线
- 计时动图（GIF）
- 权重敏感性曲线

### Q4：考虑通信延迟和测量噪声的有功功率优化与求解

**题目要求**
- 处理两类退化：
  - **测量噪声**：相对误差 ±10% 以内
  - **通信延迟**：最大 10s 以内，延迟期间**只能用上一个正常通信时刻的数据**优化
- 完善 Q3 方案，使在噪声+延迟下仍有效
- 附件4（10台、300s、已加噪延迟）作为**测试集**检验鲁棒模型
- 需展示并比对优化效果（要求同 Q3），并**展示模型对噪声和延迟的抑制能力**

**核心难点**
1. **延迟导致数据过期** —— 需设计"用旧数据优化"的补偿机制（预测/外推/鲁棒优化）
2. **噪声导致目标函数失真** —— 需滤波或鲁棒目标
3. **要"证明"抑制能力** —— 必须有对照实验（有模型 vs 无模型）

**候选建模路线**

| 路线 | 思路 | 针对 |
|:--|:--|:--|
| **① 状态预测补偿** | 对延迟时段用 Kalman 滤波/时序外推补出当前状态 | 延迟 |
| **② 鲁棒优化** | 把噪声建模成有界不确定性，优化最坏情况 | 噪声 |
| **③ 滤波 + 抗噪目标** | 输入侧滑动/自适应滤波，目标侧改用平滑后的损伤估计 | 两者 |
| **④ 敏感性惩罚项** | 目标中加一项"解对扰动不敏感"的正则 | 两者 |

**建议：①+③ 组合**（预测补偿 + 滤波），并用 ② 的鲁棒思想定形式。

**验证方案**（含**对照实验**，这是题目的硬要求）
- **有模型 vs 无模型**（直接套用 Q3 理想模型）的优化效果对比
- 不同噪声水平（0%、5%、10%）下的性能退化曲线
- 不同延迟水平（0、2、5、10s）下的性能退化曲线
- 与无噪声无延迟的理想解（上界）的差距

## 5. 假设敏感性预检

> 本节列出**会改变模型结构**的歧义项，各给至少两种解释。

### 歧义 1：Q1 的"任意时段"含义
- **解释 A**：只需支持 0~100s 的单段窗口
- **解释 B**：需支持任意起点/任意长度的滑动窗口（真正的"在线"）
- **取用**：倾向 **B**（题目说"实时计算"，应是滑动窗口），并保证 A 为其特例
- **影响**：决定算法是否必须有"增量更新"能力

### 歧义 2：Q1 输出粒度
- **解释 A**：只输出每秒损伤**增量**
- **解释 B**：输出累积值
- **取用**：**两者都要**（题目要求"每秒疲劳损伤值"入表 + "累积增长过程"作图）
- **影响**：不大，累积是增量的前缀和

### 歧义 3：Q2 的参照值来源
- **解释 A**：附件2 直接给了 $T_s, F_t$ 参考值
- **解释 B**：需自行从附件1 反推
- **取用**：**待数据确认**（这是门禁 A 的关键问题之一）
- **影响**：决定 Q2 是"标定"还是"机理推导"，直接影响是否需防过拟合

### 歧义 4：Q3 的两目标处理
- **解释 A**：加权求和（$\min w_1 \bar D_{shaft} + w_2 \bar D_{tower}$）
- **解释 B**：Pareto 前沿 + 折中解
- **取用**：**A 为主**（题目要"权重值"），B 作为补充分析
- **影响**：决定是否需要做 Pareto 计算

### 歧义 5：疲劳损伤是否归一化
- **解释 A**：直接用 Palmgren-Miner 原始 $D$
- **解释 B**：归一化到 [0,1] 或相对值
- **取用**：**A 为计算口径**（物理含义明确），展示时可比值化
- **影响**：影响优化的目标量级与权重设计
