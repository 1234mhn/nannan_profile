# 任务：为论文「问题一」重画一张流程图（学术极简风）

## 背景
这是中国研究生数学建模竞赛论文《算力约束下提升大语言模型能力的资源配置建模》中
「问题一 数据质量评价与领域配比」的流程图。

## 输入素材
1. `源图.png` —— 用户原本的流程图（信息齐全但排版杂乱，作为**内容依据**，不是风格依据）
2. `../paper.md` —— 论文全文（问题一相关章节在 §5.1，可查证术语准确性）

## ❌ 上一版失败原因（必须避免）
上一次画出来的是「分栏说明海报」而不是流程图：
- 块与块之间几乎全是**并列关系**，没有清晰的流程走向
- 每个框里塞了**大段说明文字**（像正文摘要），这是错的
- 箭头太细、被框挤压，看不出先后顺序
- 左右两栏各自堆叠，读者不知道先做哪一步

## ✅ 本次要求（不要再来海报）

### 1. 必须是真正的流程图
- **有明确主干走向**：一个步骤接一个步骤，箭头清晰、粗、短
- **判断/分叉要显式**：用菱形或明确的岔路口，标明分支条件
- **框内只放关键词/短句**（建议每框 ≤ 12 字），详细解释放图注或论文正文，**绝不塞进框里**
- 每个节点用「名词短语」命名，如「指标预处理」「熵权加权」「冲突标记」

### 2. 布局
- 主走向：**从上到下**（论文插图惯例，便于缩放嵌入）
- 语言：中文
- 画布比例建议 3:4 或 2:3（竖版），留白充足

### 3. 内容结构（依据源图 + 论文 §5.1）
主干（大致，可按逻辑优化）：
1. 输入 A1—A3（272505 条记录 / 7 领域 / 22 指标）
2. 指标预处理（方向统一 + 归一化）
3. 分叉：
   - 支路 A：六类语义分组 → 组内中位数聚合 → 熵权 w(g) → 综合质量 S(s)
   - 支路 B：同域秩变换 → 冲突强度 c(s) → 90% 阈值标记 → 加权中位数稳健评分 S*(s)
   （A、B 两支并行，最后汇合）
4. 汇合：质量模块验证（Bootstrap 200 次，95% 条件区间）
5. 汇合输出1：质量评分 + 冲突标记 + 稳健评分

然后接子任务三（配比建模）：
6. 输入 A4—A15（17 维配比 + 验证 Loss）
7. 单纯形约束与特征构造
8. 分叉：线性岭回归（基线） / 二阶岭回归（组合效应）
9. 训练与模型选择（五折交叉验证、R²/RMSE/配对 Bootstrap）
10. 独立验证（1M 同尺度 + 1B 跨尺度）
11. 汇合输出2：局部配比效应 + 适用边界

12. 最终输出：质量评分与不确定性 + 冲突稳健评价 + 局部配比效应及适用边界

子任务一/二 与 子任务三 可以用**两个纵向区块（泳道）**区分，但区块内部仍要是严格的流程链。

### 4. 风格：学术极简
- 配色：**低饱和、最多 2–3 个主色**（如深蓝灰 + 深米棕 + 灰），黑白打印可区分
- 线框：细线（0.8–1.2 pt），统一圆角
- 字体：中文用 **Noto Sans CJK SC**（系统已装：
  `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`），字号分 2–3 级
- 无阴影、无渐变、无 3D、无装饰图标
- 不要在图里放"图例说明一段话"这种元素

### 5. 输出
- `流程图_问题一_v2.png`（≥200 dpi）
- `流程图_问题一_v2.pdf`（矢量，便于嵌入论文）
- 保存到 `/root/.openclaw/workspace/flowchart_q1/`

### 6. 技术建议
- 推荐 **matplotlib**（环境已装，字体已装，最稳定）
- 或 **graphviz**（需 `pip install graphviz` + apt 装 dot，先检查再决定）
- 不建议用纯 HTML/CSS 截图（字体和矢量导出麻烦）
- 画完**必须自己检查**：箭头是否连上、文字是否溢出框、是否有重叠、
  PNG 能否正常渲染（可用 tesseract 粗查文字生成是否正常）
