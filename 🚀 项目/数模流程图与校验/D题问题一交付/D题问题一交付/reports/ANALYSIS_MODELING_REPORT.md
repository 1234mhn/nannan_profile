## 1. 总体建模框架

本题是一个**四层递进的协同优化问题**，公共物理底座为"DEM 地形 + 三段式飞行能耗 + 三维通信链路"，四问在同一底座上逐层加约束：

```
公共底座：DEM 地形 / 水平直线航段 / 爬升-巡航-下降三段能耗 / 电池两阶段充电
   │
   ├─ Q1 单点往返能力与组批   ← 只有"能力边界 + 装箱"，无调度、无通信
   │
   ├─ Q2 异构多点多架次调度   ← Q1 组批 + 异构机队 + 共享电池 + 时限（无通信）
   │
   ├─ Q3 通信约束联合调度     ← Q2 + 连续通信约束 + 中继悬停选址
   │
   └─ Q4 任务分区与资源配置   ← Q3 完整方案 + 分区划分 + 资源核算
```

**数据继承关系（论文必须交代）**：
- Q2 继承 Q1 的机型-服务区能力边界（载荷上限、能量边界）
- Q3 继承 Q2 的货箱组批与访问顺序，叠加通信可行域
- Q4 **不重算** Q3 的组批/顺序/中继安排，仅在此基础上做划分与资源核算

## 4. 问题分析

### Q1 单点往返运输能力与货箱组批方案

**题目要求**
1. 计算三种机型在不同服务区执行单点往返任务的**最大安全载荷**；
2. 货箱不可拆、每箱只排一次，满足**载质量、装载体积、返航安全能量余量**，确定各服务区**货箱组批方案**；
3. 综合**架次数、总运输能耗、累计作业时间**优化组批，说明指标间权衡/优先关系；
4. 讨论**返航安全余量变化**对最大安全载荷与组批结果的影响。

**输入**：节点坐标与海拔、30m DEM、三机型参数、80 个货箱属性
**输出**：45 组「机型×服务区」最大安全载荷表；15 个服务区的组批方案；三指标对比与权衡分析；ρ 灵敏度曲线
**决策变量**：每个服务区的货箱分批（每批 = 一个架次，机型 g 可选）
**目标**：多目标 —— min 架次数 / min 总能耗 / min 累计作业时间
**约束**：
- 载质量：Σ_{k∈批} m_k ≤ min(Q_g, q_g,i^max)
- 装载体积：Σ_{k∈批} v_k ≤ V_g
- 返航安全：E_p^T ≤ (1-ρ_g)·E_g^use
- 不可拆分、每箱一次、不跨服务区

**关键物理模型**（题目附录 2 原文口径）
- 等效航程：`L_g(q) = L_g0 - (L_g0 - L_gF)·q^{3/2} / Q_g^{3/2}`
  ⚠️ 注意 q 的 **3/2 次幂**（非线性），载荷越高航程下降越快
- 航段飞行时间：`t_ij^g = h_ij^+ / v_g↑ + d_ij / v_g^c + h_ij^- / v_g↓`
- 航段能耗：`E_ij^g(q) = E_ij^hor(q) + E_ij^up(q)`（下降不单独计能量）
- 巡航海拔：航段经过 DEM 像元**最高地面高程 + 50m**；O01 作业高度 = 地面海拔；服务区作业高度 = 地面海拔 + 30m
- **已完成计算**（§2.3）：15 个服务区的沿线最高地面与巡航海拔

**与其他问题依赖**：Q1 是 Q2 的能力边界输入（载荷上限、单架次能耗）

**求解方法**
- 最大安全载荷：对每个 (g, S_i) 以 q 为未知量，由"往返能耗 ≤ (1-ρ)E_use"反解 → **二分法**（能耗对 q 单调增），停止条件 |Δq| < 1e-6·Q_g
- 组批：**二维装箱（质量+体积）**；先贪心构造可行解（按体积利用率或质量降序装入），再用**局部搜索**（箱交换/批合并）优化
- 多目标：**加权和法 + ε-约束法**生成帕累托前沿；三指标（架次/能耗/时间）非完全一致（C 机架次少但能耗高），需显式讨论优先关系
- 灵敏度：ρ ∈ [0.10, 0.30] 扫描，重算载荷上限与组批，报告架次/能耗变化
- 复杂度：45 次二分（每次 O(1)）+ 15 次装箱（每服务区 ≤ 15 箱，可精确枚举/DP）

**计划图表**：① 三机型×15 服务区最大安全载荷热力图；② 组批方案示意（服务区-架次-箱）；③ 三指标权衡散点/帕累托前沿；④ ρ 灵敏度曲线

### Q2 异构无人机多点多架次运输调度

**题目要求**
1. 综合考虑**配送及时性、全部任务完成时间、运输能耗、架次数**进行优化，说明指标间权衡关系；
2. 给出**运输路线、架次安排、逐箱送达时刻、无人机与电池资源使用**，并检验资源可行性。

**输入**：Q1 的能力边界 + 8 架异构无人机 + 共享电池库存 + 时限约束
**输出**：完整调度方案（路线/架次/逐箱时刻/资源占用表）+ 多目标指标
**决策变量**：
- 货箱组批（每箱归属架次）
- 服务区访问顺序（每架次路径）
- 运输机型与具体执行无人机
- 共享电池分配
- 各架次开始时刻

**目标**：多目标 —— ① 配送及时性（时限达成/延误）② 全部任务完成时间（所有机完成末架次返回 O01 的最晚时刻）③ 运输能耗 ④ 架次数
**约束**：
- 货箱不可拆、载质量/体积（同 Q1）
- 返航安全余量（同 Q1）
- **无人机数量**：8 架（A×4, B×2, C×2）
- **共享电池数量**：A×6, B×4, C×4；同机型内可调度，**跨机型不可混用**
- **充电周转**：两阶段等效充电模型，占用与充电时段**不得重叠**，不同资源可并行充电
- **物资时限**：医疗物资期望送达时间、首批保障货箱截止时间（3600s）、其他物资期望送达时间（及时性指标）

**关键物理模型（新增）**
- 两阶段充电（题目附录 2 原文）：
  - 0 ≤ s < 0.90：`t_chg(s) = T_full·[0.65·(0.90-s)/0.90 + 0.35]`
  - 0.90 ≤ s ≤ 1：`t_chg(s) = T_full·0.35·(1-s)/0.10`
- 任务结束后剩余 SOC 按可用能量与实际能耗计算，不得低于返航下限；再投入前须充至 100%
- 多服务区连访：每次投送后**从 30m 作业高度重新爬升**

**与其他问题依赖**：Q2 依赖 Q1 的载荷边界；Q2 的组批与顺序是 Q3 的输入

**求解方法**
- 问题本质：**异构车队 VRPTW（带时间窗与多车场）的无人机变体 + 双资源（机+电池）调度**
- 主算法：**ALNS（自适应大邻域搜索）** 或 **遗传算法**；初始解用"时限优先 + 最近邻"启发式构造
- 电池调度：**事件驱动仿真**（按时间轴推演占用/充电/释放），保证时段不重叠
- 多目标：加权和 + 帕累托前沿；**先保证可行解**（全部箱按时送达的可行调度），再优化指标
- 校验：资源可行性四查 —— 无人机数不超、电池数不超、充放电时段不重叠、能量不超限
- 复杂度：VRP 为 NP-hard；8 架机、80 箱、15 节点的规模适合元启发式（目标 10³~10⁴ 次迭代收敛）

**计划图表**：调度甘特图、无人机与电池资源占用热力图/时间线、路线空间图、指标维度的帕累托前沿

### Q3 通信约束下的运输与中继联合调度方案

**题目要求**
1. 综合考虑**物资配送及时性、联合任务完成时间、运输与中继总能耗、两类无人机使用架次**优化，说明权衡关系；
2. 给出**运输与中继联合调度方案**，说明货箱交付、资源使用、通信保障情况。

**输入**：Q2 的调度骨架 + 通信链路参数 + DEM + 中继机 R
**输出**：联合方案（运输 + 中继）+ 通信保障报告
**决策变量**（在 Q2 基础上新增）：
- 中继无人机的**悬停位置**（经纬度）
- **飞行海拔**
- **服务时段**（起止时刻）
- **能源组件分配**

**目标**：多目标 —— ① 配送及时性 ② 联合任务完成时间（运输机与中继机全部完成末架次返回 O01 的最晚时刻）③ 运输与中继总能耗 ④ 两类无人机使用架次
**约束**：
- 货箱时限、载荷与能量（同 Q2）
- **连续通信**：运输机在**爬升、巡航、下降及物资投送全过程**均应保持连续通信
- **通信拓扑**：运输机↔G01 直连；直连不可用时经**一架中继机**建立"运输机—中继机—G01"两段链路；**不允许中继机之间多跳转发**
- **中继悬停位置**须位于 DEM 覆盖范围内，**悬停离地高度 ≤ 300m**
- 中继机往返能耗满足返航电量要求

**关键物理模型（题目附录 3 原文口径）**
1. **地形遮挡判定**：两端点三维连线与沿途 30m DEM 判定，记 `b_ij^t ∈ {0,1}`
2. **接收门限**：`P_th^b = P_sens^b + M^b`
3. **方向链路预算**：`L_max^{a→b} = P_t^a + G_t^a + G_r^b - L_sys - P_th^b`
4. **双向判定取小**：`L_max^{a↔b} = min(L_max^{a→b}, L_max^{b→a})`
5. **自由空间损耗**：`L_FSPL,ij^t = 32.45 + 20lg f + 20lg D_ij^t`（f 为 MHz，D 为 km）
6. **总损耗**：`L_path,ij^t = L_FSPL,ij^t + L_obs·b_ij^t`
7. **连通判据**：`L_path ≤ L_max` 且无遮挡（或遮挡仍在门限内）

**与其他问题依赖**：Q3 完整继承 Q2 的组批与访问顺序；Q3 方案是 Q4 的划分基础

**求解方法**
- **分层求解**：① 先用 DEM 做**视线分析（LOS）**，预计算"运输机三维位置—G01 直连可达性"空间分布；② 对直连不可达区域，**网格化候选悬停点**求覆盖最优（中继选址）；③ 在 Q2 调度骨架上做**迭代修复**（外层调度 + 内层通信校验）
- 通信可达性预计算是**性能关键**：DEM 1309×1486，需向量化采样视线，避免逐点循环
- 中继选址：可归约为**最大覆盖问题**，用贪心 + 局部搜索
- 多目标：与 Q2 一致的加权和 + 帕累托分析，指标维度扩展为中继机
- 校验：逐时刻通信状态表（每个运输机在每架次每阶段是否保持链路）

### Q4 救援任务分区与资源配置优化方案

**题目要求**
1. 分别给出划分为 **2 个**和 **3 个**任务组的分区及资源配置方案，从**资源配置规模、资源冗余、组间工作量均衡、与现有库存的资源缺口**四方面比较两种分区；
2. 若某方案所需资源超过现有库存，给出**资源缺口及其原因**。

**输入**：Q3 的完整联合调度方案（组批、访问顺序、中继安排、通信关系）+ 资源库存
**输出**：2 分区与 3 分区的方案 + 资源配置表 + 四维比较 + 缺口分析
**决策变量**：15 个服务区到任务组的**划分**（每个服务区必须且仅属于一组；每组至少一个服务区）
**目标**：四维评价（规模 / 冗余 / 均衡 / 缺口），非单目标优化
**约束**：
- 每个服务区必须且只能属于一个任务组，每组至少含一个服务区
- **保持 Q3 已确定的货箱组批、服务区访问顺序、运输与中继任务安排及通信保障关系不变**
- **若同一运输架次同时涉及多个服务区，则这些服务区应划入同一任务组**（架次不可拆 → 硬绑定）
- 各任务组仅承担本组服务区的任务；**任务执行期间各类资源不得跨组调配**

**关键难点**
- 分区不是自由聚类，而是**被"架次"绑定的约束划分**：先由 Q3 方案导出"服务区共架次图"，再做**连通图划分**
- 资源核算需**分组重算**：运输无人机、共享电池、中继无人机、中继能源组件四类资源在拆组后各自需要独立配置（原本共享的资源会出现"重复占用"）
- 四维指标定义需明确：
  - 配置规模：各组所需资源总套数
  - 资源冗余：配置量 − 实际峰值占用
  - 均衡：各组工作量（架次数/能耗/时长）的极差或方差
  - 缺口：需求 − 库存（与 8 架机 / A6-B4-C4 电池 / 1 架中继对比）

**与其他问题依赖**：Q4 **强依赖 Q3 的完整方案**，不可独立求解

**求解方法**
- ① 从 Q3 方案构建服务区-架次关联（图结构，边 = 共架次）；② **图划分**（目标：均衡 + 少跨组边）→ 用**谱聚类 / KL 算法 / 贪心连通划分**；③ 每组按 Q2/Q3 的资源核算模型**独立重算**资源需求；④ 四维指标矩阵化对比 2 组 vs 3 组
- 约束处理：共架次约束作为**硬约束（merge 后再划分）**，即先把共架次服务区合并为"超节点"，再对超节点做划分
- 复杂度：15 服务区（超节点更少），可**精确枚举**所有合法 2 分组与 3 分组，保证最优

**计划图表**：2/3 分区空间示意图、资源配置对比表、四维指标雷达图、缺口分析表

## 5. 假设敏感性预检

对影响结果的歧义，给出至少两种解释并验算选型：

**(1) 巡航海拔的"作业高度"口径**
- 解释甲：每段航段独立按"该段经过的 DEM 最高点 + 50m"取巡航海拔
- 解释乙：整个架次统一取全程最高点 + 50m
- **采用甲**（题面原文"计划巡航海拔取该航段所经过 DEM 像元的最高地面高程以上50米"），并可对比乙作为灵敏度项。

**(2) 服务区作业高度的基准**
- 解释甲：用附件表格给出的服务区海拔
- 解释乙：用 DEM 在服务区坐标处的采样值
- **采用甲作为节点作业高度基准，乙作为地形净空基准**，差异记入敏感性讨论（表格海拔与 DEM 值可能略有差异）。

**(3) 载荷对能耗的作用路径**
- 题目给出的是"载荷 q → 等效航程 L(q) → 时间"的间接关系，而能耗公式 `E = E_hor(q) + E_up(q)` 中 q 以**剩余载荷**出现
- **采用**：水平巡航能耗按 `E_hor = P_cruise(q) · t_cruise` 还原，其中功率随载荷变化（由等效航程关系反推），爬升附加能耗按题面"质量取计划起飞总质量"
- ⚠️ 题面附录 2 给的是**计算口径框架**，`E_hor` 与 `E_up` 的具体展开式在原文截图中可能有不完整的风险 → **登记 EVIDENCE_GAP-1**

**(4) 及时性指标的量化**
- 解释甲：用"按时送达箱数占比"
- 解释乙：用"加权延误时间"
- **采用甲为主、乙为辅**（题目对医疗/首批是硬时限，其他是"衡量配送及时性"，故主用达成率）
