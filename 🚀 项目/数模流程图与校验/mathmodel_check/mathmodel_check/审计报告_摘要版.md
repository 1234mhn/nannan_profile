## 二、必须修改的硬伤（5个）

### 🔴 硬伤1：公式2 熵权法占比公式非标准
**位置**：问题一，5.1.2节  
**公式**：`P_(s,g) = G_(s,g) / Σ_(s=1)^n G_(s,g)`

**问题**：
- 标准熵权法应对**每个指标**单独计算熵，不是"分组占比"
- 论文用的是"分组中位数的熵权变体"，但未说明

**正确做法**：
- 要么改用标准熵权法：`P_(s,j) = V_(s,j) / Σ V_(s,j)`，然后对22个指标分别求熵
- 要么在公式2前加说明："为避免同组指标重复计权，先取组内中位数，再计算组级熵权"

**影响**：评委可能认为这是公式错误，影响问题一可信度

### 🔴 硬伤2：公式20 MRC 量纲错误 18 个数量级
**位置**：问题二，5.2.2节  
**公式**：`MRC = −[N(∂L/∂N) + D(∂L/∂D)] / (2C)`

**验算**：
- 公式值：9.04e-04
- 数值微分：9.04e-**22**
- 差了 **10^18 倍**

**原因**：
- 符号表说 C 单位是 10²¹ FLOPs
- 但公式中 C=0.006·N·D 算出的是 **FLOPs**（因为N、D的单位是10^9）
- 分母 2C 缺少单位换算系数 10^18

**正确写法**：
```
MRC = −[N·(∂L/∂N) + D·(∂L/∂D)] / (2C/10^18)
```
或统一用 FLOPs 作单位，不要用 10^21 FLOPs

**影响**：图5.12纵轴数值错误，所有"单位算力边际收益"解释失效

### 🔴 硬伤4：公式33 g_N,slow 计算方法矛盾
**位置**：问题四，5.4.2节  
**论文公式**：`g_N,slow = g_C,slow / (1 + g_D/g_C · r_D)`

**论文另处写法**（562行）：
> data_growth_share = g_D/g_C = 0.9104  
> g_N,slow = (1 − data_growth_share)·g_C,slow

**验算**：
- 用公式33（假设r_D=0.9105）：g_N,slow = **0.1439/年** ❌
- 用替代写法：g_N,slow = **0.0236/年** ✓（与论文一致）

**问题**：两种写法数值相差 **6倍**！

**正确公式应该是**：
```
g_N,slow = (1 − g_D/g_C) · g_C,slow = g_C,slow − g_D,slow
```

**影响**：用错误公式会导致参数前沿预测偏大6倍

### 🔴 硬伤5：公式37 参数前沿预测完全对不上
**位置**：问题四，5.4.3节  
**公式**：`log10 N(t+h) = log10 N(t) + g_N,slow·h`

**论文值**：
- 12个月后：log10(N) = **10.921**
- 24个月后：log10(N) = **11.530**

**我的验算**（用g_N,slow=0.0236/年）：
- 12个月（1年）：10.344 + 0.0236×1 = **10.368** ❌（差0.55）

**问题根源**：
- 论文说 g_N,slow=0.0236/**年**
- 但实际预测值暗示用的是 **月增速**（或年增速被算错了24倍）

**影响**：问题四的核心结论（24个月预测）**完全不可信**，图5.20需重新计算
