## 二、必须修改的硬伤

### 1. **公式2：熵权法占比公式错误**（问题一，236-240行）

**位置**：5.1.2节，公式2

**问题**：
```
P_(s,g) = G_(s,g) / Σ_(s=1)^n G_(s,g)
```
这个公式对熵权法是**错误的**。标准熵权法应该：
- 先对每个指标正向化/归一化（论文做了）
- 然后计算**每个指标**的熵，不是按分组的"占比"

**正确写法**（标准熵权法）：
应该直接对归一化后的指标值 V_(s,j) 计算熵：
```
P_(s,j) = V_(s,j) / Σ_(s=1)^n V_(s,j)
E_j = − Σ_(s=1)^n P_(s,j)·ln P_(s,j) / ln n
w_j = (1 − E_j) / Σ_(h=1)^22 (1 − E_h)
```

**论文的做法**：
论文先取组内中位数 G_(s,g)，再按组计算熵权。这是一种**分组简化**的变体，但：
1. 公式2写的"占比"概念在这里是**误导性的**——这不是"样本s在组g中的占比"，而是"样本s的组中位数在全部样本该组中位数之和中的比例"
2. 这种写法在数学上可以运行，但**不是标准的熵权法**

**影响**：
- 如果评委熟悉标准熵权法，会认为这是错误公式
- 建议要么改用标准熵权法，要么在公式2前明确说明"为避免同组指标重复计权，本文采用分组中位数的熵权变体"

### 2. **公式20：MRC公式存在量纲问题**（问题二，384行）

**位置**：5.2.2节，公式20

**问题**：
```
MRC = −∂L_2/∂C = −[N(∂L_2/∂N) + D(∂L_2/∂D)] / (2C)
```

**验算结果**：
- 公式值：9.035037e-04
- 数值微分值：9.035037e-**22**
- **差了 18 个数量级**

**原因分析**：
论文中 C 的单位是 **10²¹ FLOPs**（符号表说明），但公式中 C=0.006·N·D 实际算出的是 **FLOPs**。
- N 单位是十亿参数（10^9）
- D 单位是十亿词元（10^9）
- C = 6×N×D 的单位应该是 10^18 FLOPs，不是 10^21 FLOPs

**正确写法**（统一到 FLOPs 单位）：
```
C = 6×10^18 · N · D  （单位：FLOPs）

MRC = −∂L/∂C = −[N·(∂L/∂N) + D·(∂L/∂D)] / (2C/10^18)
```
或者明确写成：
```
MRC = −[N·(∂L/∂N) + D·(∂L/∂D)] / (2 × 0.006 × N × D)
```

**影响**：
- MRC 的数值结果会差 10^18 倍，影响所有单位算力边际收益的解释
- 图5.12的纵轴单位需要修正

### 4. **公式33：g_N,slow 计算公式有歧义**（问题四，551-552行）

**位置**：5.4.2节，(4) 算力放缓情景

**论文公式**：
```
g_N,slow = g_C,slow / (1 + g_D/g_C · r_D)
```

**论文另处写法**（5.4.3节，562行）：
> 数据增长占比为 0.9104
> g_N,slow = (1 − data_growth_share)·g_C,slow

**验算结果**：
- 用公式33：g_N,slow = 0.2632 / (1 + 0.9105×0.9105) = **0.1439/年** ❌
- 用替代写法：g_N,slow = (1 − 0.9105)×0.2632 = **0.0236/年** ✓（与论文一致）

**问题根源**：
公式33 中 r_D 的含义不清：
- 如果 r_D = 1（全部份额），则两式等价
- 如果 r_D = g_D/g_C（论文暗示的"比例"），则公式不自洽

**正确写法应该是**：
```
g_N,slow = (1 − data_growth_share) · g_C,slow
其中 data_growth_share = g_D / g_C
```
即简化为：
```
g_N,slow = g_C,slow · (1 − g_D/g_C) = g_C,slow − g_D,slow
```

**影响**：
- 用错误公式会导致 g_N,slow 偏大 6 倍
- 直接影响公式37的参数前沿预测

## 四、需要澄清的不严谨之处

### 1. 公式19 的因子问题（问题二，382行）
**公式**：`∂L_2/∂Q = −L_0·κμ(1−Q)^(μ−1)`

**澄清**：
- 论文写的是 **L_0**（不含质量项的经典损失）
- 但 L_2 = L_p·[1+κ(1−Q)^μ]，其中 L_p = L_0·m(p)
- 严格来说，当 m(p)≠1 时，应该是 **L_p** 而不是 L_0
- 数值验证显示公式在 m(p)=1 时正确

**建议**：
- 明确说明"在参考配比 p_ref 处，m(p)=1，故 L_p=L_0"
- 或改写为 `∂L_2/∂Q = −L_p·κμ(1−Q)^(μ−1)`

### 2. KKT 公式25 的符号约定（问题三，503行）
**公式**：
```
𝓛 = L(x) + λ(C_total−C) − Σ_j u_(j,−)(x_j−x_j^min) + Σ_j u_(j,+)(x_j−x_j^max)
```

**澄清**：
- 论文用的是**最小化问题**（min L）
- 预算约束 C_total ≤ C 等价于 C_total−C ≤ 0
- **标准 KKT** 应写成：`𝓛 = L + λ(C_total−C)`，其中 λ≥0（不等式约束乘子）
- 下界约束 `x_j≥x_j^min` 等价于 `−(x_j−x_j^min)≤0`，应为 `−u_(j,−)(x_j−x_j^min)`，u_(j,−)≥0
- 上界约束 `x_j≤x_j^max` 等价于 `(x_j−x_j^max)≤0`，应为 `+u_(j,+)(x_j−x_j^max)`，u_(j,+)≥0

**论文的写法可以运行**，但符号约定需要说明：
- 如果用的是对偶变量的"物理意义"（边界推力），则需要解释符号
- 建议补充一句："其中 λ、u 均为非负拉格朗日乘子"
