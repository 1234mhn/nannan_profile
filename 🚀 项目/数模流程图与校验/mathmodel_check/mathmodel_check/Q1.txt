
问题一模型建立与求解
本问以全量质量信号构建分组熵权评分，以百分位秩识别指标冲突并进行稳健聚合，再用线性配比模型及二阶组合模型解释交叉熵损失。全量记录评分、同尺度独立预测、跨尺度诊断及外推表检验采用明确区分的统计口径。质量排序具有一定方法稳健性，但不能解释为各领域对预训练任务的普遍价值排序。

3 分组熵权综合评价模型
3.1 模型定义
为减少同类评分器数量不同造成的重复计权，将22个指标归为六组。各组先取中位数，再依据组间信息差异计算熵权。分组依据指标语义设定；相关结构仅能提供辅助证据，不能仅凭相关均值差异宣称分组有效。
⁅Gs,g = median{ Vs,j : j ∈ group g }⁆
⁅Ps,g = Gs,g / ∑s=1n Gs,g⁆
⁅Eg = −∑s=1n Ps,g ln(Ps,g) / ln(n)⁆
⁅wg = (1−Eg) / ∑h=16(1−Eh) ;   Ss = ∑g=16 wg Gs,g⁆
约定0 ln 0=0。熵权反映当前附件中组评分的离散程度，并非因果重要性。域级S_d取该域全部记录的S_s算术均值，不额外假设各域Token规模；故该值是记录平均质量，不能直接表述为Token加权语料质量。
⁅Sd = ∑s:domain(s)=d Ss / nd⁆

3.2 不确定性口径
在每个领域内，以“领域＋id”定义文档簇，对簇进行200次bootstrap抽样；同一文档的重复记录一起进入重采样。固定预处理尺度和组权重，以域均值的2.5%与97.5%分位数构成条件区间。区间不包含评分器偏差、权重估计误差和语料抽样代表性误差，不能替代人工质量标注。

5 质量冲突识别与稳健聚合
5.1 冲突定义与消解规则
对各指标V采用平均并列秩，同值对应同秩。令rank_avg为1起算的并列平均名次，以R=(rank_avg−0.5)/n形成百分位秩。冲突强度定义为同一样本在不同指标上的最大秩差：
⁅Rs,j = (rank_avg(Vs,j)−0.5)/n ;   cs = maxj Rs,j − minj Rs,j⁆
⁅δ = quantile(c, 0.90) ;   conflicts = 1{cs ≥ δ}⁆
全量样本的δ=0.967960，强冲突记录27,252条，占10.00%。90%分位数是预设筛选强度，约10%的比例由规则决定，不视为独立发现。该定义衡量评价分歧，不直接等同于劣质、广告或有害内容。
稳健消解在同一秩尺度进行。把组权重均分至组内指标，令w_j=w_g/组内指标数，定义秩加权均值S_rank作为对照，并取加权中位数S_star。加权中位数是加权绝对偏差之和的最小化解，降低极端指标的影响：
⁅wj = wg/|group g| ;   S_ranks = ∑j=122 wjRs,j⁆
⁅S_stars ∈ arg mint∈[0,1] ∑j=122 wj|Rs,j−t|⁆
取满足累计权重至少为0.5的最小观测秩；所有样本均输出S_star，强冲突标记用于优先复核。主质量S保持分组熵权定义，不把两种尺度拼接成一列。所谓消解指形成稳健综合判断，并未改变原始指标，也不使c自动减小。

强冲突记录上|S_star−S_rank|的均值为0.1086，其余记录为0.0634。该差异说明聚合规则对冲突样本影响更大，不能作为质量改善的因果证据。book在三种阈值下均具有较高冲突率，但仅171条记录，需结合文本长度与指标适用性解释。

6.2 成因分析
扩展arxiv中的突出分歧是推理或专业性评分高而DSIR相对评分低；github中的突出分歧涉及DSIR、长度及词汇多样性。前者可能反映专业论述与参考域相似性的差异，后者可能来自短文本、代码结构及信号尺度差异。上述为数据和文本案例支持的解释，尚不能识别生成这些差异的因果机制。
不能把全域冲突统计等同于同域错误。长篇学术和书籍文本可能同时取得较高的知识、长度评分与较低的参考域相对分数；程序数组与表格可能触发重复指标，但仍含有任务信息。因此，本模型保留冲突标记，使用稳健聚合给出辅助判断，并结合原始内容解释分歧。
A2/A3无content字段，文本核验限于A1。对扩展集只做指标层面复检，不声称已经逐条检查其原文。

8 领域配比与Loss的定量模型
8.1 单纯形约束与评价目标
所有配比均非负，训练表原始行和范围为0.996—1.003。采用逐行除以行和恢复单纯形约束，保留原有零比例；训练表零元素占45.13%，直接线性模型无需给零值添加伪计数。
⁅pi,l = p_rawi,l/∑h=117p_rawi,h ;   pi,l≥0 ;   ∑l=117pi,l=1⁆
分别对13个验证域的交叉熵损失拟合模型，并以13域Loss的等权均值作为综合指标。该均值是本文评价选择，不能称为官方Token加权总体Loss。nih_exporter、enron_emails、europarl及philpapers没有同名Loss列，仅解释其对已有13个验证域的间接影响。
⁅L_meani = (1/13) ∑m=113 Li,m⁆
8.2 线性主模型与可识别约束
⁅Li,m = am+∑l=117βl,mpi,l+εi,m ;   ∑l=117βl,m=0⁆
主模型仅用A4/A5的512组1M配方估计。由于各配比之和为1，加入截距后系数存在平移不唯一性；以系数和为0固定表示。令p与L同时减去训练均值，最小二乘求beta，再令其列均值为0，恢复a=mean(L)−mean(p)@beta。
在此定义下，综合Loss截距为4.4526。β的相对差值有明确意义；将份额ε从领域j转到领域i，且0≤ε≤p_j时：
⁅ΔL_mean = ε(βi,mean−βj,mean)⁆
该变化是拟合模型中的关联效应，不是随机干预的因果效应。纯域端点或训练范围外的大幅调整缺少数据支持，因此报告1个百分点转移，并同时给出不确定性及跨尺度限制。
8.3 分尺度截距描述模型
另将全部实测表合并，1M训练与检验归入同一尺度组，60M和1B各为一组。对每组同时中心化p与L，估计共享beta_pool；截距按a_pool=mean(L)−mean(p)@beta_pool恢复。该模型用于描述已有实测数据，不再把其拟合优度称为独立检验结果。
⁅Li,m−meank(Lm) = ∑l beta_pooll,m[pi,l−meank(pl)]+εi,m⁆
修正后综合Loss的组内R²=0.3040，RMSE=0.2356。与显式尺度虚拟变量回归所得预测的最大差为1.33e-14，用于核验实现等价性。

10.1 组合影响的解释边界
二阶模型允许同一转移的预测收益随当前配方改变。对于p(ε)=p+ε(e_i−e_j)，其一阶变化率等于线性系数差，加上各交互项沿该方向的导数；其中p_i p_j项贡献γ_ij(p_j−p_i)，与其他领域h的交互贡献(γ_ih−γ_jh)p_h。因此不能只按γ_ij的正负脱离当前配方宣称互补或替代。
二阶模型参数还原至原始配比尺度，完整交互系数见interaction_coefficients.csv，可预测模型见quadratic_model.npz。部分稀有域比例很小，系数数值可能很大，实际影响还需乘以配比乘积。本文以独立预测改善作为组合项有效性的主要证据，不将大系数当作普遍配置建议。

11.1 质量评分是否进入配比模型
以A16的三个direct和三个near_direct关系，将arxiv、github、stackexchange、wikipedia_en、gutenberg_pg_19及pile_cc分别关联至对应质量域。其余11个训练域不主观补造质量值。若S_d在每个领域固定，将p_l S_d作为额外特征，则它只是p_l的常数倍；聚合质量项∑p_l S_d也位于原配比列空间内。
⁅rank([p, p×S_domain]) = rank(p) = 17⁆
实际增广秩与原矩阵秩均为17。因此，在具有自由领域系数的当前线性模型中，不能独立识别额外质量系数，本文不把S显式加入配比回归。该结论仅针对这一线性参数化及固定域质量数据，不等于质量没有作用，也不排除有额外质量变化数据或受约束模型时的识别可能。
11.2 本问结论
分组熵权模型给出了全部记录和七域质量评分；固定参考分布复检支持arxiv与github的主要冲突差异；文本核验揭示了内容质量与领域适用性的区别。同尺度配比预测中，二阶组合项优于线性基线，但1B及外推表不支持直接迁移训练尺度的偏好。故本问输出应同时保留主评分、稳健秩评分、冲突标记、配比模型及适用范围，不能压缩成无条件的全局最优领域排序。
