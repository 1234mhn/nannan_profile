题　目：大语言模型训练的多源语料质量评价与标度律建模
摘　要：
随着大规模语言模型参数规模与训练数据规模的持续增长，数据质量与领域配比已成为决定模型性能的关键因素。传统的标度律主要关注参数规模与数据量，但无法区分数据质量、领域组成与模型性能之间的独立作用。本文基于附件 A 的多源语料质量指标与领域配比数据、附件 B 的标度律实验记录以及附件 C 的模型效率配置，建立从数据质量评价到广义标度律、从标度律到资源配置优化的完整建模框架。
针对问题一，本文构建基于熵权法的多指标质量评价体系，采用秩尺度变换与 Huber 损失控制异常值，识别并标记质量评价冲突记录。在此基础上，建立领域配比与验证损失之间的二次校准模型，量化了配比偏离参考方案的损失代价。实验表明，代码与公式领域的质量评分显著高于自然语言领域，配比优化可使损失下降 0.012 nat/token。
针对问题二，本文将问题一的质量评分引入经典标度律，提出两种候选广义标度律形式：加性质量惩罚与乘性质量系数。通过 AIC、BIC 与留出误差比较，确定乘性形式为最优模型。该模型在 Q=1 时自动退化为经典标度律，参数规模弹性为 −0.146、数据量弹性为 −0.084、质量弹性为 −0.519，表明数据质量提升的边际效用显著高于规模扩张。进一步分析表明，质量从 0.5 提升至 1.0 的效果等价于参数规模扩大 2.8 倍。
针对问题三，本文以问题二的乘性质量缩放律为目标函数，将基础训练、质量提升与长上下文注意力三类开销统一折算为 FLOPs，在预算约束下联合优化参数规模、数据规模与数据质量。模型由 KKT 条件刻画边际资源配置关系，用 SLSQP 多初值求解并以确定性网格独立验证，通过 PELT 与活跃集变化共同识别结构转变。结果表明：当上下文长度超过临界值 30000 时，注意力开销单独超过基础训练开销；在低预算阶段优先提升数据质量，预算跨越约 1.334×10^19 FLOPs 后质量触及上界，新增预算主要分配给参数与数据规模。
针对问题四，本文利用附件 C 的评测与算力数据，建立有界 Logit 动力学回归模型，控制参数规模与模型类型后以时间项度量非规模技术进步，并用 Shapley 路径平均分解能力变化。结果显示，在参数前沿收缩阶段，非规模技术贡献占比达 53.34%（预训练模型）与 55.89%（对话/微调模型）。在算力增速减半情景下，预测 12 个月与 24 个月的能力前沿，并给出 95% 不确定区间；同时建立 Loss—Benchmark 分层桥接，使前三问的损失结果可换算为下游能力得分。
综上，本文形成了从数据到模型、从模型到决策、从决策到验证的完整证据链，可为大规模语言模型训练中的数据采集与资源配置提供理论依据与实用方法。

一、问题重述
1.1 问题背景
随着大规模语言模型参数规模与训练数据规模的持续增长，数据本身的构成与质量已成为决定模型性能的关键因素。传统的最小化验证交叉熵损失主要关注参数规模 N 与训练数据量 D，但无法区分数据数量、数据质量与领域组成三者的独立作用。与此同时，多源语料在采集过程中往往来自不同领域，存在质量参差不齐、指标相互冲突、配比难以优化等现实问题。如何在保持模型可解释性的前提下，将数据质量评分与领域配比纳入统一的预测与决策框架，并进一步在有限的算力预算下给出最优资源配置，是当前大规模预训练实践中亟待解决的核心矛盾。
附件 A 提供了多源语料的质量评分与领域配比实验数据，附件 B 提供了不同模型族与数据规模下的标度律实验记录，附件 C 提供了模型效率演进与上下文长度的相关配置。三组附件共同构成了从数据到规律、从规律到决策、再从决策到能力预测的完整信息链条。
1.2 问题提出
问题一：基于附件 A 提供的多源语料质量指标与领域配比数据，建立数据质量评价体系，识别并消解不同指标之间的质量评价冲突，并建立领域配比与验证损失之间的定量关系模型。
问题二：基于附件 A 的质量评价结果与附件 B 的标度律实验数据，构建同时包含参数规模 N、数据量 D、数据质量 Q 与领域配比 p 的广义标度律，分析各因素的边际效用与弹性，并推导质量提升与规模扩张之间的可替代条件。
问题三：在给定总算力预算的约束下，联合优化参数量 N、数据量 D 与数据质量 Q，考察预算跨量级变化时最优策略是否发生结构性转移，并给出相应的资源配置方案。
问题四：基于附件 C 提供的模型效率演进与评测数据，识别能力提升中来自参数规模扩张与技术进步的相对贡献，分析在算力增长放缓情景下能力前沿的演进方向，并给出面向下一阶段的前沿预测。
二、问题分析
四问之间构成递进关系：问题一从数据侧出发，输出质量评分与配比关系；问题二将问题一的输出作为输入，刻画质量与配比对损失的影响规律；问题三以问题二的标度律为目标函数，在算力约束下给出最优决策；问题四在问题二、三给出的损失侧规律之上，进一步把损失结果桥接到下游能力得分，分析能力前沿的驱动来源并给出预测。
问题一属于评价与回归问题。其切入角度是先建立可解释的质量指标体系，再用稳健统计方法处理指标冲突，最后建立配比与损失的定量模型。需要的数据包括 A1—A3 的多源语料质量指标、A4—A5 的配方与损失表，以及 A6—A15 的不同尺度检验表。预期产出为域级质量评分、冲突标记以及配比系数，为问题二提供 Q 与 p 的取值依据。
问题二属于规律拟合与模型比较问题。其关键难点在于如何将质量 Q 与配比 p 合理地引入经典标度律，同时保证模型在 Q 取理想值时能够退化为经典形式。本文通过构造两种候选形式并以 AIC、BIC 与留出误差择优来解决这一问题。
问题三属于带约束的非线性优化问题。其目标函数为问题二建立的广义标度律，约束为包含基础训练开销、质量提升开销与长文本注意力开销的算力预算，决策变量为参数规模、数据量与数据质量。该问题的核心在于识别最优解随预算变化的定性结构。
问题四属于结构分解与趋势外推问题。其难点在于评测口径不一致、参数量与算力高度共线，直接回归容易把规模效应误判为技术进步。本文采用统一口径榜单聚合，以有界 Logit 动力学回归控制参数量与模型类型后以时间项度量非规模技术进步，再用 Shapley 路径平均分解能力贡献，并在算力增速放缓情景下给出前沿预测与不确定区间。
三、模型假设与符号说明
3.1 模型基本假设
本文的模型假设针对现实中可能存在的复杂状况与各类误差影响而设立，不为简化计算而假设掉题目给出的关键条件，具体如下：
(1) 同一模型系列的验证损失可分解为不可约损失、有限参数损失与有限数据损失三部分，该假设把训练轨迹映射为可估计的二项幂律形式。
(2) 质量得分 Q 越大表示数据质量越高，Q=1 表示无额外质量惩罚的基准水平，该假设保证广义形式在理想质量下退化为经典标度律。
(3) 领域配比的影响在参考配比 p_ref 邻域内可由二次函数局部校准，即 m(p)=exp[−ηΔ_p(p)]，该处理把较低的配比损失映射为较大的有效数据量。
(4) 同一 run_id 内的检查点具有轨迹相关性，因此统计推断以完整轨迹为抽样块，不把全部检查点视为独立重复观测。
(5) 跨模型族允许绝对损失存在族间截距差异，跨族数据采用族内留一偏移校准判断曲线形状，不修改主模型的尺度参数。
(6) 半合成质量实验数据分别估计而不直接合并，当参数触及边界或拟合方向相反时，将其解释为适用性失败而非强行平均。
(7) 不主观删除正值离群记录，采用 Huber 损失降低异常残差的影响；非正数据量记录按缺失处理。
(8) 各领域质量指标采用“自然语言可读性及知识表达”的方向假设，并以去除文本形态组作为敏感性对照，对代码、公式与表格不作绝对优劣判断。

五、模型建立与求解
5.1 问题一模型建立与求解
5.1.1 问题一求解思路
问题一的核心任务是建立多源语料的质量评价体系，识别并消解指标间的评价冲突，并进一步建立领域配比与验证损失之间的定量关系。本文的技术路线为：先对 22 个质量指标做方向统一与归一化，再以语义分组抑制同类评分器的重复计权，构建分组熵权综合评价模型得到域级质量评分；随后以百分位秩定义冲突强度，采用加权中位数做稳健聚合；最后在单纯形约束下建立配比与损失的线性模型与二阶组合模型，并做独立检验与跨尺度诊断。整体求解思路如图 5.1 所示。

5.1.2 问题一模型建立
（1）指标预处理与方向统一
各指标的含义以原数据集字段说明核验。fineweb_edu 提取单值；ad_en 取“无广告”减“有广告”的 logit 差，fluency_en 取“流畅”减“不流畅”的 logit 差，两者均为正向。四个 modernbert 字段为 0—5 级分类输出，以 softmax 期望等级保留连续信息：
X_(s,j) = Σ_(k=0)^5 k·exp(z_(s,j,k)) / Σ_(k=0)^5 exp(z_(s,j,k))
实际计算先减去最大 logit 以避免溢出。qurater 四维分别描述文风、知识门槛、事实知识与教育价值，采用四项原始评分的等权均值，属于建模选择而非原题指定权重。计数指标取 ln(1+x)，三个 DSIR 字段在本数据中全部非正，取 ln(1−x) 后反向归一化，以保留“原始 DSIR 越大越优”的相对方向。将正向指标缩放为 V=(X−min)/(max−min)，反向指标取 1−V；常量列设为 0.5 并将熵权置零。全部 22 个指标的处理规则如表 2 所示。
（2）分组熵权综合评价模型
为减少同类评分器数量不同造成的重复计权，将 22 个指标归为六组。各组先取中位数，再依据组间信息差异计算熵权。记组内中位数为 G_(s,g)，则：
P_(s,g) = G_(s,g) / Σ_(s=1)^n G_(s,g)
E_g = − Σ_(s=1)^n P_(s,g)·ln P_(s,g) / ln n
w_g = (1 − E_g) / Σ_(h=1)^6 (1 − E_h)
S_s = Σ_(g=1)^6 w_g · G_(s,g)
约定 0·ln0=0。熵权反映当前附件中组评分的离散程度，并非因果重要性。域级质量评分 S_d 取该域全部记录的 S_s 算术均值，不额外假设各域 Token 规模。
（3）冲突识别与稳健聚合
对各指标 V 采用平均并列秩，同值对应同秩。令 rank_avg 为 1 起算的并列平均名次，以 R=(rank_avg−0.5)/n 形成百分位秩。冲突强度定义为同一样本在不同指标上的最大秩差：
c_s = max_j R_(s,j) − min_j R_(s,j)
δ = quantile(c, 0.90);　conflict_s = 1{c_s ≥ δ}
稳健消解在同一秩尺度进行。把组权重均分至组内指标，令 w_j=w_g/|group g|，定义秩加权均值 S_rank 作为对照，并取加权中位数 S_star。加权中位数是加权绝对偏差之和的最小化解，可降低极端指标的影响：
S_star_s ∈ arg min_(t∈[0,1]) Σ_(j=1)^22 w_j·|R_(s,j) − t|
（4）领域配比与损失的定量模型
所有配比均非负，训练表原始行和范围为 0.996—1.003。采用逐行除以行和恢复单纯形约束，保留原有零比例：
p_(i,l) = p_raw_(i,l) / Σ_(h=1)^17 p_raw_(i,h),　p_(i,l) ≥ 0,　Σ_(l=1)^17 p_(i,l) = 1
分别对 13 个验证域的交叉熵损失拟合模型，并以 13 域 Loss 的等权均值作为综合指标。线性主模型形如：
L_(i,m) = a_m + Σ_(l=1)^17 β_(l,m)·p_(i,l) + ε_(i,m),　Σ_(l=1)^17 β_(l,m) = 0
主模型仅用 A4/A5 的 512 组 1M 配方估计。由于各配比之和为 1，加入截距后系数存在平移不唯一性，以系数和为 0 固定表示。在保留线性解释模型的基础上，进一步引入 136 个 p_i·p_j 二阶项，采用岭回归抑制过拟合：
L_mean = a_quad + Σ_(l=1)^17 β_quad_l·p_l + Σ_(i<j) γ_(i,j)·p_i·p_j + ε
对特征按训练折均值和标准差标准化；截距不惩罚，最小化残差平方和加 λ 倍系数平方和。λ 候选为 0.01、0.1、1、10、100、1000，只在 512 组训练配方内进行相同划分的 5 折验证，检验集不参与选 λ。

5.2 问题二模型建立与求解
5.2.1 问题二求解思路
问题二的核心任务是在经典标度律的基础上，显式引入数据质量 Q 与领域配比 p，建立同时包含 N、D、Q、p 的广义标度律，并据此分析各因素的边际效用与弹性，量化“提升数据质量”与“扩大模型规模”之间的可替代条件。
本文的技术路线为：先以 B1 真实训练日志稳健拟合经典 Chinchilla 型标度律，获得不可约损失与规模项参数；随后固定经典参数，构造两种候选的质量扩展形式——有效数据量式与乘性质量式；在 B6 上分别估计新增参数，并以 AIC、BIC 与 B7 留出误差择优；最后通过轨迹分块 Bootstrap、B7 新增点、B3 训练轨迹、B4 与 B5 跨模型族数据以及 B9、B10 大模型资料进行分层验证，计算弹性、单位算力边际收益（MRC）与质量—参数替代关系。
附件 B 同时包含真实训练日志、插值轨迹、跨模型族观测、半合成质量实验和估计型大模型损失。建模的核心是**按证据性质分工**：B1 识别基础规律，B6 估计质量参数，B7 新增点检验外推，B8 检查方向一致性，B3—B5 验证迁移，B9—B10 讨论百亿参数以上外推。各数据文件的作用与规模如表 4 所示。

5.2.2 问题二模型建立
（1）经典标度律的稳健拟合
同一模型系列的验证损失可分解为不可约损失、有限参数损失和有限数据损失，据此建立经典 Chinchilla 型二项幂律：
L_0(N, D) = E + A_N · N^(−α) + A_D · D^(−β)
其中 E 为不可约损失，A_N 与 A_D 分别为参数项与数据项系数，α 与 β 为相应指数。经典参数采用 Huber 非线性最小二乘稳健估计：
x_hat = arg min_x Σ_k ρ_δ[L_0(N_k, D_k; x) − L_k],　x = log(E, A_N, A_D, α, β)
其中 ρ_δ 为 Huber 损失，用于降低异常残差的影响。N 与 D 直接进入幂律，不做 Z-score；所有正参数在对数参数空间优化，以自动满足正值约束。
（2）领域配比的有效性修正
附件 B 没有逐条领域配比，拟合时取均匀参考配比 p_ref。p 的影响由问题一的二次配比模型在 p_ref 邻域校准，定义相对 p_ref 的配比损失差及有效性乘子如下：
Δ_p(p) = f_p(p) − f_p(p_ref),　m(p) = exp[−η · Δ_p(p)]
f_p(p) = a_quad + Σ_i β_i·p_i + Σ_(i<j) γ_(ij)·p_i·p_j
该处理把较低的配比损失映射为较大的有效数据量，同时限制跨尺度解释范围。
（3）两种候选的质量扩展形式
候选形式一（有效数据量式）把质量和配比共同映射为有效数据量，并保留低质量惩罚：
D_eff = D · Q^(θ_Q) · m(p)
L_1 = E + A_N·N^(−α) + A_D·D_eff^(−β) + G[Q^(−γ) − 1]
候选形式二（乘性质量式）先用 m(p) 修正数据量，再让质量作用于完整经典损失：
L_p = E + A_N·N^(−α) + A_D·[D·m(p)]^(−β)
L_2 = L_p · [1 + κ(1 − Q)^μ]
两种形式在 Q=1、p=p_ref 时均自动退化为经典标度律。对每种候选模型计算残差平方和 SSE，并以参数个数 k 惩罚复杂度：
AIC = n·ln(SSE/n) + 2k,　BIC = n·ln(SSE/n) + k·ln n
（4）弹性、替代与边际收益
主模型选择 L_2。在 p=p_ref 处令 F(Q)=1+κ(1−Q)^μ，则各维度的偏导数为：
∂L_2/∂N = −F·α·A_N·N^(−α−1)
∂L_2/∂D = −F·β·A_D·D^(−β−1)
∂L_2/∂Q = −L_0 · κμ(1 − Q)^(μ−1)
定义弹性 ε_X = (X/L_2)·(∂L_2/∂X)，X∈{N, D, Q}。按 C=0.006·N·D 计算训练量，若扩展路径保持 D/N 不变，则 N 和 D 均与 C 的平方根成正比。单位算力边际损失下降（MRC）与质量—参数替代率分别为：
MRC = −∂L_2/∂C = −[N(∂L_2/∂N) + D(∂L_2/∂D)] / (2C)
dN/dQ = −(∂L_2/∂Q) / (∂L_2/∂N)
有限质量提升 δ_Q 对应的等效参数规模 N_equiv，由 L_2(N_equiv, D, Q) = L_2(N, D, Q + δ_Q) 求得。

5.3 问题三模型建立与求解
5.3.1 问题三求解思路
问题三的核心任务是在算力预算有限时，求解参数量 N_B、数据量 D_B 与数据质量 Q 之间的最优配置，并分析当预算水平变化时最优分配是否发生本质改变。长上下文又会额外引入与 N_B、D_B 和 L_ctx 共同增长的注意力计算，使仅按 6ND 配置训练资源失去准确性。
本文的技术路线为：在问题二乘性质量缩放律基础上，把训练计算、质量提升和长上下文注意力统一折算为 FLOPs；在给定预算 C 与外生上下文长度 L_ctx 下联合优化 N_B、D_B 和 Q。模型先由 KKT 条件刻画边际资源配置关系，再用 SLSQP 多初值求解、确定性网格独立验证，并在连续预算扫描上采用 PELT 与活跃集变化共同识别结构转变。
本问的输入由问题二主模型参数、问题一 Q_0 与 p_star、C7 的 L_ctx 以及题设成本参数组成。最终采用问题二经 BIC 和留出误差共同选出的乘性质量缩放律作为目标函数，第三问只改变资源约束，不重新拟合损失函数，从而保持跨问题参数口径一致。
5.3.2 问题三模型建立
（1）决策变量与成本构成
决策变量为 N_B、D_B 和 Q；领域配比 p 固定为问题一参考配比附近的局部最优 p_star；L_ctx 作为外生场景量，不参与优化。基础训练成本、质量提升成本与注意力成本分别为：
C_train = 6×1018 · N_B · D_B
C_quality = 109 · D_B · [g(Q) − g(Q_0)]_+
C_attn = η_attn × 1018 · N_B · D_B · L_ctx
其中 η_attn=2×10−4，Q_0 由问题一真实结果计算为 0.605095。总成本满足 C_train + C_quality + C_attn ≤ C。预算取 1019、1022 和 1024 FLOPs，并用 61 个对数等距预算点检查连续变化。C7 共 45 条有效记录，L_ctx 的观测范围为 2048 至 131072，五个实际场景为 2048、4096、8192、32768 和 131072。
（2）质量成本函数选取
质量成本分别采用指数型、幂函数型和对数渐进型三种形式：
指数型：g(Q) = a·[exp(b(Q − Q_0)) − 1]
幂函数型：g(Q) = a·(Q − Q_0)^b
对数渐进型：g(Q) = a·ln(1 + b(Q − Q_0))
三种形式分别求解，不将其参数混合估计。该处理把成本机制不确定性转化为模型情景比较，避免用缺少观测依据的权重合成三种函数。N_B、D_B 的优化范围沿用问题二数据支撑范围：0.070542 ≤ N_B ≤ 10000、0.1 ≤ D_B ≤ 36000；Q_0 ≤ Q ≤ 1。
（3）优化模型与 KKT 条件
在固定 p_star 下，第二问乘性质量模型可写为 L = L_p·[1 + κ(1−Q)^μ]。完整优化模型为：
min L(N_B, D_B, Q)　s.t.　C_train + C_quality + C_attn ≤ C
预算紧约束允许消去 D_B，用于独立网格验证。注意力成本与基础训练成本之比为：
C_attn / C_train = (η_attn · L_ctx) / 6
该比值不依赖 N_B、D_B 和预算。令 x=(N_B, D_B, Q)，C_total=C_train+C_quality+C_attn，以 u_(j,−) 和 u_(j,+) 表示变量下、上界乘子，拉格朗日函数为：
𝓛 = L(x) + λ(C_total − C) − Σ_j u_(j,−)(x_j − x_j^min) + Σ_j u_(j,+)(x_j − x_j^max)
当 N_B、D_B 和 Q 均为内部解时，KKT 驻点条件可写成相同的单位算力边际损失下降：
M_N = M_D = M_Q = λ
若 Q=1，则互补松弛给出 M_Q ≥ λ；若 Q=Q_0，则 M_Q ≤ λ。由 C_attn/C_train 的常数比可得使注意力开销与训练开销相当的临界上下文长度：
L_ctx_crit = 6 / η_attn = 30000
（4）结构转变的识别方法
定义连续预算扫描的标度指数 ξ(C) = d ln(N_B·D_B) / d ln C。将三类成本份额、Q 和 ξ(C) 标准化为序列 z_i，PELT 求解：
min Σ_i [ Σ_(t∈段) ‖z_t − z̄_段‖² + β·|段数| ]
结构转变表现为成本份额、最优质量或标度指数的统计分段变化，并结合质量变量活跃集核验。该处理把结构变化转化为 PELT 可识别的多变量变点，避免人为设置份额跳变阈值。

5.4 问题四模型建立与求解
5.4.1 问题四求解思路
问题四的核心任务是分离并量化大语言模型能力提升中的规模扩张贡献与非规模技术进步贡献，并在算力增长放缓的情景下预测开源模型的能力前沿。本问的难点在于双重尺度差异：前三问输出为交叉熵损失，而现实评测使用多维 Benchmark 得分；同时未来算力增速被设定为放缓，需要把规模路径与技术项共同外推。
本文的技术路线为：以 C1 一致口径榜单为主样本，用六项任务等权均值定义综合能力；在控制参数规模和模型类型后，以时间项表示非规模技术进步，并用 Shapley 路径平均分解能力变化；由 C4 给出开放权重模型的算力、数据量和参数前沿，构造算力增速减半情景；C6 完成 Loss 到 Benchmark 的分层桥接，C8 则从最新有效 JSON 重新聚合 BBH 子任务。整体技术路线如图 5.13 所示。

5.4.2 问题四模型建立
（1）综合能力的构造与样本口径
综合能力采用 IFEval、BBH、MATH Lvl 5、GPQA、MUSR 和 MMLU-PRO 六项 0—100 得分的等权均值。六项任务保持原始尺度，不做 PCA。入选模型须存在 Hub 条目且许可证字段明确；排除缺失、other 和 unknown，保留允许研究或复现的具名许可证。模型类型分为 pretrained 与 chat_finetuned，multimodal 和 other 不进入主动力学回归；时间轴采用 Submission Date，数据截止日为 2025-03-13。
（2）有界 Logit 动力学回归模型
为应对线性外推突破评分边界的问题，将综合得分经 Logit 变换后建模：
logit(S/100) = β_0 + β_logN·log10(N) + β_time·t + β_time_chat·(t·I_chat) + ε
其中 N 为参数量，t 为距 2024-06-08 的年数，I_chat 为模型类型指示变量，t·I_chat 为时间交互项，允许两类模型的技术演进速度不同。回归自变量使用 log10 参数量。参数以 Huber 损失稳健估计，降低榜单离群值的影响：
θ_hat = arg min_θ Σ_k ρ_δ[ logit(S_k/100) − f(N_k, t_k, I_chat,k; θ) ]
（3）Shapley 贡献分解
从起点 (N_0, t_0) 到终点 (N_1, t_1) 的规模与技术贡献采用两条反事实路径的 Shapley 平均。令 F(N, t) 为反变换后的预测得分，则规模贡献 Δ_scale 与技术贡献 Δ_tech 分别为：
Δ_scale = ½{[F(N_1,t_1) − F(N_0,t_1)] + [F(N_1,t_0) − F(N_0,t_0)]}
Δ_tech = ½{[F(N_1,t_1) − F(N_1,t_0)] + [F(N_0,t_1) − F(N_0,t_0)]}
该处理避免非线性变换下分解顺序影响结果。前沿由同类型模型 Logit 残差 90% 分位定义，规模路径由窗口内参数量 90% 分位表示，以降低单个异常冠军模型对前沿的支配。
（4）算力放缓情景与参数前沿路径
C4 完整年份的规模路径满足近似关系 C ∝ N·D。算力增速减半并保持数据增长份额后：
g_C,slow = 0.5 · g_C,　g_N,slow = g_C,slow / (1 + g_D/g_C · r_D)
其中 r_D 为训练数据占算力增速的比例，沿用 2021—2024 年经验比值。算力放缓设为 C4 完整年份历史对数增速的 50%。
（5）Loss—Benchmark 分层桥接
C6 桥接比较线性与二次模型，以加权留一误差选择。高可比样本权重为 1，中可比样本权重为 0.35，并单独标注外推：
B_hat = a_0 + a_1·L + a_2·L²
实际选择结果为线性形式，即 a_2=0。C8 逐任务均值与 C1 口径不同，因此再估计线性校准式 B_hat_C1 = c_0 + c_1·B_task。
