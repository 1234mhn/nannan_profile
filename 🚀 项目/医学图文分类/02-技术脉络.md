# 02 · 技术脉络：从 ConVIRT 到 M3GCD

> 每个方法写三件事：之前的问题 X / 它的解法 Y / 留下的问题 Z。

## 阶段 ① 图文对比学习起源（2020）

### ConVIRT（2020，⚠️待核实）｜奠基
- **一句话**：把「医学图像 ↔ 对应报告」当成一对，用对比学习让配对的图文在特征空间靠近。
- **解决的**：在此之前医学图像分类依赖人工标签；ConVIRT 把报告变成了免费监督信号。
- **留下的**：整张图对整份报告，粒度太粗；配对关系被当成硬 0/1。
- ⚠️ **待核实**：年份、出处。来源为 2026-11-10 组会记忆（"2020 ConVIRT，综述未单列"），
  我未读原文，也未核对综述 Table 2。

## 阶段 ② 医学适配（2021–2023）

### GLoRIA（2021，⚠️待核实）｜局部对齐
- **一句话**：不整图对整文，把图切块、把文本切词，做局部级别的对比对齐。
- **解决的**：病灶占像素比例极低，全局对齐信号被背景淹没。
- **留下的**：**"切细了，但没切干净"** —— 按空间块切，块里病灶和背景混在一起。
  来源：2026-11-10 组会讲稿原话（已获认可的口径）。
- ⚠️ 待核实：具体切法（网格切块还是区域检测）、数据集与指标。

### MedCLIP（EMNLP 2022）｜软标签治假阴性
- **一句话**：解耦图文配对（n 对 → (n+m)×(n+h)），用 MetaMap 抽 UMLS 实体算语义相似度，替代 InfoNCE 硬标签。
- **解决的**：A 病人报告写"肺不张"、B 病人报告也写"肺不张"，传统对比学习把两者当负样本强行推远 —— 假阴性。
- **留下的**：MedFILIP 引用它并明确指出「false negative 问题未解决透」。
- **关键数字**（来源 `memory/2026-10-26.md`，我对原文有精读稿但此处仅转引）：
  - 零样本 CheXpert 0.4328(GLoRIA) → **0.5942**
  - COVID 0.7090 → **0.8472**；RSNA 0.5808 → **0.7418**
  - 微调 CheXpert 0.5370 → **0.5960**；2 万对胜 20 万对 GLoRIA；单卡 RTX-3090 / 8 小时

### MedKLIP（ICCV 2023，DOI 10.1109/ICCV51070.2023.01954）｜抽病名 + 领域先验
- **一句话**：从报告里抽出疾病实体，把疾病名与图像 patch 做对照，并注入医学知识模板。
- **解决的**：模型只学到"表观语义"，缺少临床概念层级依赖。
- **留下的**：丢上下文/子类；对没见过的病无能为力。
  来源：2026-10-27 memory（"🅱️ 病名派（MedKLIP）：丢上下文/子类（2a）、没见过的新病（2b）"）。
- ⚠️ 待核实：具体模板内容、抽取方式（是否用规则/词典）。

### BioMedCLIP（年份⚠️待核实）｜领域数据重训
- **一句话**：用大规模生物医学图文对重新训练 CLIP，得到领域专用的图文编码器。
- **与本文库关系**：它更像是**底座**而不是方法创新 —— 很多下游工作直接拿它的权重做初始化。
- ⚠️ 待核实：确切发表年份、数据规模、许可。**素材中只有名称出现，没有可靠细节**。

## 阶段 ③ 细粒度与对齐精度（2024–2025）

### CP-CLIP（MICCAI 2024 + TMI 2025, Vol.44 No.10, pp.3973-3983, DOI 10.1109/tmi.2024.3482228）
- **一句话**：不改编码器、不改损失，把网络里的全连接层换成**核心—外围图指导的连接**（用邻接矩阵 A 逐元素乘权重矩阵 W），让"核心节点连所有节点、外围节点只连核心、外围之间不连"。
- **解决的**：对比学习在全局层级做对齐，病灶占像素极低，语义粒度单一。
- **留下的**：**核心与外围之间的关系没有建模**（2026-11-10 组会反复确认的缺口）。
- 详细内容与三个常见误读见 [[CP-CLIP]] 卡片。

### MedFILIP（arXiv 2501.10775 / JBHI 2025, DOI 10.1109/jbhi.2025.3528196）｜拆属性 + 译成视觉语言 + 软标签
- **一句话**：LLM（GPT-3.5）把报告拆成「疾病/位置/程度」，把疾病名翻译成"视觉上长什么样"，再用文本相似度矩阵替代 0/1 标签，分别与图像对齐。
- **解决的**（三个问题三招）：
  - 非结构化 → **GPT-IE** 结构化抽取
  - 缺视觉描述 → **IKI** 疾病名翻译成视觉描述
  - 假阴性 → **SSM** 语义相似矩阵做软标签
- **关键数字**：零样本 ACC 最高提升 **+6.69%**（MIMIC-multi 64.37 → **71.06**）；消融 63.9 → 67.2 → 70.6 → 73.3 → **74.7**。
- **主动交代的短板**：ChestX-ray14 上 85.67 输给 MedKLIP 的 86.19。
- 详见 [[MedFILIP]]。

### MedTrim（JBHI 2026, DOI 10.1109/jbhi.2026.3678306）｜实体感知三元组
- **一句话**：用领域本体识别病理形容词、限定词、方位词，构建实体感知的三元组挖掘评分来捕捉层级相似度，加多模态对齐目标。
- **解决的**：对比学习只做粗粒度疾病类分离，漏掉位置/大小/严重度等细粒度属性 → 表征次优。
- **与 MedFILIP 的区别**（我的推导）：同样盯"属性"，MedFILIP 用 LLM 生成视觉描述（生成式），MedTrim 用本体+三元组（判别式/结构化）。**两者可互补。**
- 阅读状态：**泛读**。详见 [[MedTrim]]。

## 阶段 ④ 架构重构（2022–2026）

### MedViLL（IEEE JBHI 2022）｜早期融合 + 双向注意力
- **一句话**：ResNet 图像编码 + BERT 文本编码，中间加**双向注意力**（图像 Q 查文本 K/V，文本 Q 查图像 K/V），并设计多模态注意力掩码，一套预训练同时做理解（分类/检索/VQA）与生成（报告生成）任务。
- **解决的**：CLIP 式双塔只有对齐、没有交互；医学任务里理解与生成需要同一套底座。
- **留下的**：掩码设计复杂；报告的非结构化文本是它的优势区，同时可能也是它的边界（摘要里"尤其擅长医学图像 + 非结构化报告"）。
- 详见 [[MedViLL]]。

### CheXmix（arXiv 2604.22989，Stanford AIMI，⚠️仅泛读摘要+memory）
- **一句话**：VQ-GAN 把胸片编成 1024 个离散 token，与文本 token 拼进同一序列，**没有投影层**；两阶段训练（自回归预测 + 掩码重建）。
- **解决的**：LLaVA 式「CLIP 编码器 + 投影层 + LLM」的投影层会扭曲视觉细节，而医学影像的细微征象至关重要。
- **关键数字**（来源 memory/2026-10-26 与 2026-11-10）：CheXpert 分类 AUROC 比 CheXagent **+8.6%**；报告生成 GREEN **+45%**；图像修复 **+51.0%**；**检索没赢**；**低掩码率 0-20% 打不过 SigLIP**。
- **与 MedViLL 的关系**（已确认口径）：相隔五年主张一样（早期融合），MedViLL 靠掩码控制，CheXmix 干脆不要掩码 ——「掩码从核心创新退成不需要」。
- **诚实定位**：图文 token 化 + 无投影层借自 Chameleon；原创在两阶段训练 + 医学领域首次系统验证。
- **算力**：4×A100 80G，121 万步 → **不可复现，只能读**。
- ⚠️ 待核实：未读原文，数字转引自 memory。

## 阶段 ⑤ 开放类（2026）

### M3GCD（IEEE TMI 2026）｜图文双模态 + 动态权重 + 自动发现新类
- **一句话**：用图像+临床文本对做广义类别发现（GCD），DEF 动态分配每个病例的图文权重、LEB 保护单模态独有线索、CD 类别扩散自动增减类别数。
- **解决的**：现有 GCD 只用图像、融合权重固定、要求预知未知类数量。
- **关键数字**：对比最强基线 GET，MIMIC-CXR / PatchGastric / MM-Retina 各 **+3.5% / 4.1% / 4.7%**（All 类平均准确率）。
- **留下的**（组会批判）：DEF 路由器学到的"重要性"是否真反映临床规律，论文未充分归因；训练重（200 epoch、8×RTX 4090）。
- 详见 [[M3GCD]]。

## 贯穿全线的三条「卡点」（组会口径，已获导师认可）

| 卡点 | 卡在哪 | 谁在补 |
|:--|:--|:--|
| **粒度** | 全局对齐 → 局部对齐（GLoRIA 切细但没切干净）→ 结构化解耦（CP-CLIP 后半段）→ 属性级（MedFILIP/MedTrim） | GLoRIA → CP-CLIP → MedFILIP → MedTrim |
| **数据** | 配对不一定对，语义重叠报告被当负样本 | MedCLIP → MedFILIP(SSM) |
| **维度** | 预训练语料二维，CT/MRI 只能 2D 切片 | MG-3D / Merlin / fVLM ⚠️待核实 |

## 我的推导（明确标注）

1. 四个阶段其实是**两种不同的思路在交替**：
   - ①②③ 都在"在 CLIP 框架内改零件"（改损失、改粒度、改先验）；
   - ④ 开始改框架本身（改架构、改任务设定）。
   若找创新点，**在 ③ 里继续加零件风险最高**（人太多），**在 ④ 里问"框架该不该这样"更有空间**。
2. MedViLL(2022) 和 CheXmix(2026) 的主张相同 —— 说明**有些问题被提出很早，但直到工程条件成熟才被重新采纳**。这类"回锅问题"是性价比很高的选题来源。
