## 这个库是干什么的

一条主线：**医学图像 + 报告文本，怎么把两者对齐起来做分类。**
目标有三个：
1. 能在一小时内把这十年的技术脉络讲清楚（组会/开题用）；
2. 把「别人还没解决的问题」摊开列在一张表上（找创新点用）；
3. 自己的实验进展、数据、复现路径有地方落（写论文用）。

## 领域主线图（文本版）

```
① CLIP 范式（2020 ConVIRT 起）
   把「图-报告」当成一对，整图整文对比学习
   代表：ConVIRT(2020) → CLIP 原生路线
   留下的问题：粒度太粗、配对不一定对

② 医学适配（2021–2023）
   在 CLIP 骨架上补医学特性：局部对齐 / 软标签 / 领域先验
   代表：GLoRIA(2021 局部块对齐)、MedCLIP(2022 语义软标签治假阴性)、
        MedKLIP(2023 抽病名+模板)、BioMedCLIP(领域数据重训)⚠️待核实

③ 细粒度（2024–2025）
   不再满足于「整图对整文」，开始拆属性、拆结构
   代表：CP-CLIP(2024/2025 网络连接结构拆核心-外围)、
        MedFILIP(2025 LLM抽属性+翻译成视觉描述+软标签)、
        MedTrim(2026 实体感知三元组)

④ 开放类 / 架构重构（2024–2026）
   ├─ 架构重构：MedViLL(2022 早期融合双塔互看) → CheXmix(2026 图文token早期同序列, 无投影层)
   └─ 开放类  ：M3GCD(2026 图文双模态 + 动态模态权重 + 自动发现新类)
```

**一句话记住四个阶段：**
> 先对齐（①）→ 再补医学特性（②）→ 再往细里切（③）→ 最后有人开始问「对齐这件事本身该怎么组织、能不能不止分已知类」（④）。

**贯穿全线的三句话（来源：2026-11-10 组会口径，已获导师认可）：**
1. 粒度这条线：GLoRIA 切细了但没切干净 → CP-CLIP 接着做后半段。
2. 数据这条线：配对不一定对，语义重叠的报告被当负样本 → MedCLIP 起用软标签。
3. 维度这条线：还停在二维，3D 才刚开头（MG-3D / Merlin）。

## 怎么用这个库

### 场景 A：想快速了解进展（1 小时）
1. 读 [[02-技术脉络]] 的「一句话版」（每阶段 3 行）—— 20 分钟
2. 翻 [[_模板-方法卡片]] 旁边五张卡片里的「一句话做了什么」—— 20 分钟
3. 读 [[01-研究背景]] 的「一句话版本」，组会开场直接念 —— 5 分钟
4. 其余时间回看 [[00-README]] 的主线图

### 场景 B：想找创新点（半天）
1. **先看 [[09-联动与索引]] 层一的空行** —— 整行 ❌/— 的痛点就是空白地带（如 C3、F3、F4）
2. 再看 [[10-领域全景图]] 里标 `[ 空白 ]` 的位置，判断是真空白还是假空白（假空白 = 有人想过但没做成，更容易出成果）
3. 到 [[06-创新点池]] 看现有候选，判断能否再加一条
4. 每条新想法必须挂回一个痛点双链 —— 挂不上的想法大概率是伪需求
5. 用 [[09-联动与索引]] 层三看每条想法缺什么证据，再用 [[07-技术栈与复现]] 估算力与数据

### 场景 C：想写论文
1. [[01-研究背景]] 提供 Introduction 的动机段（报告=免费监督信号；闭集→开集）
2. [[02-技术脉络]] 提供 Related Work 的三条主线组织方式
3. [[03-任务与评测]] 决定用哪套数据集和指标
4. [[08-我的进展日志]] 记录消融与失败实验，写作时直接翻

## 维护约定

0. **痛点、方法、想法三处要一起改**：新增痛点 → [[09-联动与索引]] 层一加行 → [[06-创新点池]] 评估 → 层二/层三补齐。单改一处会让联动表失真。
1. **不动原稿**：本库只读 `文献/`、`🎓 读研/`、`memory/` 下的原文件，要补充信息就在本库里加，不去改原件。
2. **一张卡一篇文**：新论文 → 先在 `05-方法卡片库/` 复制 [[_模板-方法卡片]]，填完再把双链加进 [[00-README]] 和方法卡片列表。
3. **不确定就标 ⚠️待核实**：宁可留空，不凭印象填数字。来源可以是「某篇精读稿」「组会讲稿」「memory 某日」。
4. **痛点加创新点要成对**：新增痛点 → 在 [[06-创新点池]] 评估是否有对应想法；新增想法 → 必须写清「来源痛点」双链。
5. **进展日志按日期追加**：`## YYYY-MM-DD`，不改历史条目，错了就在后面补一条更正。
6. **本库不碰代码**：实验代码放 `🚀 项目/脑部CT-CLIP分类/`，本库只记录结论与路径。
