# 数学建模优化题型全清单（比赛速查版）

> 用户提供，2026-09-17 落盘。用于比赛时 30 秒判题型、选算法。
> 配套六步法：①题目原文 → ②圈三零件 → ③判题型 → ④选算法+说为什么 → ⑤Python代码能跑 → ⑥看结果+灵敏度分析

## 🅰️ 第一层：按"数学结构"分（决定用什么求解器）

| 编号 | 题型 | 特征 | 算法 | 工具 | 关键词 |
|---|---|---|---|---|---|
| A1 | 线性规划 LP | 目标+约束全线性，变量连续 | 单纯形法、内点法 | scipy linprog、PuLP、LINGO | 在…约束下使…最大/最小（全是加减乘常数） |
| A2 | 整数规划/0-1规划 IP | 变量必须整数，或只能0/1 | 分支定界、割平面、匈牙利算法（指派） | PuLP、Gurobi、scipy milp | 选/不选、个数为整数、安排几个 |
| A3 | 非线性规划 NLP | 目标或约束含平方、乘积、指数、三角 | 梯度下降、牛顿法、BFGS、SQP、拉格朗日+KKT | scipy minimize、MATLAB fmincon | 效率、距离、面积、比例、幂次 |
| A4 | 多目标优化 MOP | 两个以上互相冲突的目标 | 加权求和、ε-约束、NSGA-II、Pareto前沿 | pymoo、platypus | 既要…又要…、成本与效益、平衡 |

## 🅱️ 第二层：按"问题场景"分（决定怎么建模）

### B1. 选址/布局 🏗️
- 变量：0-1 变量 xᵢ（在哪建）
- 目标：成本最小 / 覆盖最大 / 距离最短
- 约束：覆盖要求、数量限制、容量
- 算法：0-1 规划 + 聚类（K-means + 重心法）+ 遗传算法
- 例题：充电桩布点、基站选址、仓库选址、医疗点布局

### B2. 调度/排程 ⏰
- 变量：xᵢⱼ（任务 i 是否在时段 j）、顺序变量
- 目标：总工期最短 / 延误最小 / 成本最低
- 约束：时间窗、资源冲突、工序先后、机器容量
- 算法：整数规划、动态规划、规则启发式（SPT/EDD）、遗传、禁忌搜索
- 例题：生产排程、车辆调度、排课、手术室排程

### B3. 路径/网络 🗺️
- 变量：xᵢⱼ（边是否走）
- 目标：总路程最短 / 成本最低 / 流量最大
- 约束：流量守恒、容量限制、路径连续
- 算法：Dijkstra/Floyd（最短路）、最大流最小割、最小费用流、TSP（蚁群/遗传）
- 例题：物流配送、管网设计、交通流、通信网络

### B4. 资源分配 💰
- 变量：xᵢ（给对象 i 分多少）
- 目标：总效益最大 / 成本最小 / 公平性最优
- 约束：总量上限、单项上下限、整数要求
- 算法：LP、IP、动态规划、多目标优化
- 例题：预算分配、产能分配、水资源配置、人力安排

### B5. 参数寻优/工程优化 ⚙️
- 变量：设计参数（尺寸、角度、比例、系数）
- 目标：性能指标最优
- 约束：物理限制、安全系数、取值范围
- 算法：NLP、遗传算法、PSO、模拟退火（+仿真耦合）
- 例题：外形优化、结构设计、控制参数整定

### B6. 存储/库存优化 📦
- 变量：每次订货量 Q、订货周期 T
- 目标：总成本最小（订货费 + 持有费 + 缺货费）
- 约束：需求率、提前期、资金限制
- 算法：EOQ 模型、（s,S）策略、随机库存优化
- 例题：经济订货批量、安全库存设定

### B7. 排队优化 🚻
- 变量：服务台数量 c、服务率 μ
- 目标：总成本最小（等待成本 + 服务成本）
- 约束：到达率 λ、服务强度 ρ<1
- 算法：M/M/1、M/M/c、M/G/1 公式 + 优化
- 例题：窗口数量、设备配置、客服排班

### B8. 博弈/决策优化 🎯
- 变量：各方策略
- 目标：各自收益最大 / 均衡
- 约束：策略空间
- 算法：纳什均衡、Stackelberg 博弈、线性互补
- 例题：定价策略、竞合关系、政策博弈

### B9. 装箱/切割/覆盖 📐
- 变量：物品放哪个箱 / 怎么切
- 目标：箱数最少 / 浪费最小 / 覆盖最全
- 约束：容量、尺寸、几何约束
- 算法：整数规划、分支定界、FFD/BFD 启发式、遗传
- 例题：集装箱装载、板材切割、覆盖选址

## 🅾️ 第三层：按"解法策略"分（决定求解路径）

| 编号 | 策略 | 内容 | 适用 |
|---|---|---|---|
| C1 | 精确算法 | 单纯形、分支定界、割平面、动态规划、枚举 | 变量<几百、结构规整 |
| C2 | 启发式规则 | 贪心、SPT、EDD、最近邻、FFD/BFD | 快速出可行解，作为基准 |
| C3 | 元启发式 | GA通用组合优化 / SA跳出局部 / PSO连续参数少 / ACO路径类 / TS带记忆调度类 / DE连续收敛快 | 大规模 |
| C4 | 机器学习辅助优化 | ML预测目标/约束再优化（代理模型、贝叶斯优化） | 目标函数要跑仿真、太贵 |
| C5 | 灵敏度分析（必做） | 改参数→看结果变化→画图→说明稳定性 | 研赛拉分点 |

## ⚡ 比赛时 30 秒决策流程
1. 圈出"决策变量"（我能定什么）
2. 圈出"目标"（我要最优什么）
3. 圈出"约束"（什么不能越）
4. 看方程形式 → 线性？整数？非线性？多目标？（A1~A4）
5. 看场景 → 选址？调度？路径？分配？参数？（B1~B9）
6. 看规模 → 小规模精确解 / 大规模元启发式（C1~C3）
7. 跑通 → 画图 → 灵敏度分析 → 写论文

| 优先级 | 模块 | 用途 |

| 🟠 2 | 遗传算法（DEAP/自写） | 规模大时救命 |
| 🟡 3 | 灵敏度分析脚本 | 必做、拉分 |
