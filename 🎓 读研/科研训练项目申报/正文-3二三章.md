# 二、研究目标、内容和拟解决的主要问题

## 1 研究目标

本项目围绕影像报告弱监督条件下的医学图像疾病分类开展研究，深入分析报告语义解析、细粒度视觉—语言对齐和层次化分类在医学图像智能诊断中的作用。项目重点围绕报告语义粒度过细且夹杂冗余表述、局部匹配关系未被显式建模、分类结果缺乏可回溯依据以及跨中心条件下性能衰减等问题展开研究。

一份影像报告同时包含检查类型、解剖部位、阳性征象、程度修饰和阴性排除意见，其语义层次远细于"一个疾病类别"这一标签粒度。现有方法多将整份报告压缩为单一文本表示，与整幅图像做全局对比学习，模型实际学到的是"这类检查常见哪些表述"的粗粒度关联，而非"图像中哪一区域对应报告中哪一句判断"。当同一图像包含多种病变，或同一疾病在报告中以不同方式表述时，全局对齐容易造成多病混淆和假阴性。若改为从报告中抽取结构化病名作为标签，虽降低了建模难度，却丢弃了位置、程度和伴随征象等信息，模型在训练集中未出现的新疾病上难以适应，也无法为预测提供依据。

本项目拟构建一种融合报告语义多粒度结构化解析、匹配关系图建模和层次化分类的医学图像分类框架。通过大语言模型将非结构化报告解析为具有临床语义层级的结构化表示，在病灶级建立语义单元与图像区域的细粒度对应；通过匹配关系图显式建模局部匹配之间的解剖邻近性与病理共现性，为相似征象的消歧提供依据；通过层次化分类头将细粒度表征映射到疾病类别，并使预测结果能够回溯到具体的报告描述片段。

项目拟以胸部 X 线为主要验证模态，该模态具有公开图文数据规模大、报告书写相对规范、类别体系较为清晰的特点，适合开展细粒度对齐与层次分类实验；同时根据数据条件向 CT 和病理模态扩展，考察方法的跨模态适应能力。

本项目的总体目标是形成一种对人工标注依赖较低、能够利用报告中细粒度证据、分类依据可回溯且跨中心条件下相对稳健的医学图像分类方法，使模型在大规模无标注图像—报告对上完成预训练后，能够在标注有限的病种和机构上取得可用性能。

项目研究拟为影像报告的自动结构化、病灶级视觉—语言对应关系分析和层次化辅助诊断提供技术基础，为人工智能技术在医学影像辅助诊断中的应用提供参考。

## 2 研究内容

本项目以报告弱监督条件下的医学图像分类为研究背景，从监督信号构建、跨模态表征学习和分类决策三个层面开展研究。针对报告语义冗余、粒度失配、局部匹配关系缺失、分类依据不可追溯和跨中心泛化不足等问题，拟重点开展以下三项研究。具体内容如图 1 所示。

### 2.1 基于大语言模型的报告语义多粒度结构化解析

影像报告以自然语言书写，不同机构在模板结构、术语习惯和描述详细程度上存在差异。同一种征象可能被表述为"实变""斑片状高密度影"或"炎性改变"，同一份报告也可能在描述部分与诊断印象部分重复给出结论。若直接将原始报告文本作为监督信号，模型需要同时处理语言表达的多样性和语义层级的混杂。

本项目拟以开源大语言模型为基础，构建报告结构化解析流程。解析目标是将非结构化报告转换为具有临床语义层级的结构化表示，具体包括三个层次：全局层对应检查类型与整体印象，用于确定该次检查所属的任务范围；器官层对应解剖部位及其总体状态，用于建立图像区域与解剖结构的对应；病灶层对应具体征象及其位置、程度、性质等属性修饰，用于支撑细粒度匹配。三层之间保持从属关系，使后续对齐与分类可以在明确的语义层级上开展。

在解析实现上，拟采用提示工程结合少量示例的方式引导模型完成抽取，并通过规则校验保证输出格式的稳定性。针对报告中大量出现的模板化表述与阴性排除意见，设计过滤与降权机制：模板化描述不参与细粒度对齐，阴性表述作为背景语义保留但不承担正向监督。同时拟引入术语归一化环节，将不同表述映射到统一的医学术语集合，减少表面形式差异对后续对齐的干扰。

通过上述研究，拟形成"原始报告输入—语义层级划分—实体与属性抽取—术语归一化—结构化语义单元输出"的解析流程，为细粒度对齐提供粒度一致、语义明确的监督信号。

### 2.2 细粒度图文对齐与匹配关系图建模

在获得结构化语义单元后，需要建立其与图像区域的对应关系。现有方法多采用区域特征与文本特征逐对计算相似度，再将匹配结果池化聚合。这一做法将每个匹配视为独立样本，忽略了匹配之间的关系。当图像中同时存在多个相似征象时，独立匹配容易产生歧义，例如肺部斑片影与胸膜增厚在局部区域上可能具有相似的视觉表现，仅凭单个匹配难以判断报告中的描述究竟指向哪一处。

本项目拟构建区域级与语义级的对比学习目标，替代整图与整报告的全局对齐。具体做法是将图像编码器输出的区域特征与语义单元特征在共同嵌入空间中计算匹配，并以报告中的实际描述作为正样本依据。为缓解同一语义多种表述造成的假阴性问题，拟引入软标签机制，对语义相近但表述不同的样本给予部分正样本权重。

在此基础上，拟构建匹配关系图。将每个局部匹配作为图节点，以解剖邻近性与病理共现性作为边的构造依据：若两个匹配对应同一解剖区域内的相邻结构，或对应临床常见的共现征象组合，则在节点之间建立连接。通过图推理聚合相邻节点的证据，使模型在判断某一区域语义时能够参考与之相关区域的信息，从而减少相似征象之间的混淆。关系图的结构设计将参考解剖分区先验，并在训练中通过注意力权重观察模型实际依赖的关系类型。

通过上述研究，拟形成"区域特征提取—语义单元匹配—软标签对比学习—匹配关系图推理—细粒度表征输出"的对齐流程，使监督信号落实到具体的解剖部位和病灶区域。

### 2.3 层次化分类与跨中心泛化验证

医学疾病体系本身具有层次结构，肺部疾病之下包含感染性与肿瘤性病变，前者又可细分为细菌性、病毒性和真菌感染。扁平分类器将所有类别置于同一层级，既无法利用类别之间的从属关系共享信息，也难以在样本稀少的叶节点上获得稳定表征。

本项目拟设计层次化分类头，将细粒度表征沿语义层级逐级映射：先在病灶层预测具体征象，再在器官层聚合各部位状态，最后在全局层输出诊断类别。每一级的预测均与报告解析得到的对应层级语义单元建立监督关系，使模型在训练过程中同时学习层级内部的区分和层级之间的归属。由于中间层输出与报告描述片段直接对应，分类结果可以回溯到具体的文本依据，医师在核验时能够看到模型关注的是报告中哪一句描述以及图像中对应的区域。

跨中心泛化是本项目的重要考察内容。不同医院在设备型号、扫描参数和报告书写习惯上的差异会造成系统性分布偏移，模型在内部测试集上的性能往往难以在外部数据上重现。项目拟在公有数据集与可用外部数据上开展外部验证，重点考察跨机构条件下性能衰减的幅度及其在语义层级中的分布，分析衰减主要发生在病灶层的视觉识别、器官层的区域定位还是全局层的类别归属。针对文本侧差异，拟通过术语归一化和语义层面对齐减少模型对特定表述形式的依赖。

通过上述研究，拟形成"细粒度表征输入—分层预测—语义回溯—跨中心评估"的分类与验证流程，使方法在标注有限的病种和机构上具备可用性。

## 3 拟解决关键问题

### 3.1 报告语义粒度混杂条件下的可靠监督构建问题

影像报告同时包含检查类型、解剖部位、具体征象和程度修饰，语义层次并不统一，且夹杂模板化描述与阴性排除意见。若将整份报告作为单一监督信号，模型难以判断哪些内容对应图像中的实际视觉证据；若仅抽取结构化病名，又会丢失位置、程度和伴随征象等关键信息。如何在保留细粒度信息的同时建立层次清晰、噪声可控的监督信号，是本项目需要解决的首要问题。本项目拟通过大语言模型解析构建三级语义结构，配合模板过滤、阴性降权和术语归一化，使不同层级的信息各承担相应的监督职责。

### 3.2 局部匹配关系缺失条件下的细粒度对齐问题

现有方法在完成区域与文本的逐对匹配后直接池化聚合，未考虑匹配之间的解剖邻近性与病理共现性。当图像中存在多个相似征象时，独立匹配容易产生歧义，模型难以判断报告描述指向的具体位置。如何显式建模局部匹配之间的语义关联，并利用这些关联为相似征象提供消歧依据，是细粒度对齐中的关键问题。本项目拟以匹配为节点、以解剖邻近与病理共现为边构建关系图，通过图推理聚合相关证据，并结合软标签机制缓解同一语义多表述带来的假阴性。

### 3.3 层次结构与跨中心条件下的分类稳健性问题

医学类别体系具有层次结构，不同层级的样本分布极不均衡，叶节点上的罕见病种样本稀少；同时，不同机构在设备、成像协议和报告书写习惯上的差异会造成分布偏移，模型性能在外部数据上往往明显衰减。如何利用层次结构共享信息以缓解长尾问题，并使模型在跨机构条件下保持相对稳定，是本项目需要解决的第三个问题。本项目拟通过层次化分类头在层级之间传递监督，并在跨中心数据上分析性能衰减在语义层级中的分布，据此调整对齐策略与术语归一化方案。

# 三、项目的研究思路与方法、技术路线、创新性及其可行性分析

## 1 研究思路和方法

项目针对影像报告语义冗余、粒度失配、局部匹配关系缺失、分类依据不可追溯以及跨中心泛化不足等问题，拟构建一种融合报告语义多粒度解析、细粒度对齐与匹配关系图建模、层次化分类的医学图像分类方法。项目拟以具有较大公开图文数据规模的胸部 X 线为基础验证对象，并根据数据条件向 CT 与病理模态扩展。总体技术思路为：报告结构化解析—语义单元构建—区域级对比学习—匹配关系图推理—层次化分类—跨中心验证。

### （1）构建报告语义结构化解析模块

原始报告以自然语言书写，语义层次混杂。本项目拟采用开源大语言模型完成解析，通过提示模板约束输出格式，并结合少量标注示例提升抽取稳定性。解析结果按全局层、器官层、病灶层三级组织，其中病灶层记录征象名称、位置、程度和性质等属性。

对于模板化表述与阴性排除意见，拟设计规则与语义判断相结合的过滤机制。模板描述不进入细粒度对齐流程，阴性表述作为背景语义保留但不贡献正向监督。同时拟构建术语归一化映射表，将不同表述统一到标准术语集合。

设第 i 份报告的原始文本为 R_i，解析后得到的语义单元集合为：

S_i = { (e_k, l_k, a_k) | k = 1, 2, ..., K }

其中 e_k 表示第 k 个语义单元的核心实体，l_k 表示其所属语义层级，a_k 表示位置、程度等属性集合。解析质量拟通过人工抽检的方式评估，考察项包括实体抽取的准确率与层级标注的一致性。

### （2）细粒度图文对齐与匹配关系图建模

为建立语义单元与图像区域的对应关系，本项目拟采用双编码器结构，图像侧使用预训练视觉主干提取区域特征，文本侧使用语言编码器提取语义单元特征，并在共同嵌入空间中计算匹配。

设第 j 个图像区域特征为 v_j，第 k 个语义单元特征为 t_k，二者的匹配分数为：

s_jk = <φ(v_j), ψ(t_k)> / τ

其中 φ 与 ψ 分别表示图像侧和文本侧的投影函数，τ 为温度系数。对比学习损失以报告中实际描述作为正样本依据，并引入软标签对语义相近的表述给予部分正样本权重，以缓解假阴性。

在匹配基础上构建关系图 G = (V, E)，其中节点集合 V 对应各局部匹配，边集合 E 依据解剖邻近性与病理共现性构造。图的节点表示在每轮迭代中通过注意力聚合邻居信息更新：

h_v^(l+1) = σ( W^(l) · AGG( { h_u^(l) | u ∈ N(v) } ∪ { h_v^(l) } ) )

其中 N(v) 表示节点 v 的邻居集合，AGG 表示聚合操作。通过关系图推理，模型在判断某一区域语义时能够参考相关区域的信息，从而减少相似征象之间的混淆。

### （3）层次化分类与语义回溯

在获得细粒度表征后，本项目拟设计层次化分类头完成疾病预测。分类过程沿语义层级逐级进行：病灶层输出具体征象的预测，器官层聚合各部位状态，全局层给出诊断类别。每一级的预测均与报告解析得到的对应层级语义单元建立监督，使层级内部区分和层级之间归属同时得到学习。

项目总体优化目标可概括为：

L_total = L_align + λ1 L_soft + λ2 L_graph + λ3 L_hier + λ4 L_reg

其中 L_align 为区域—语义对比损失，L_soft 为软标签正则项，L_graph 为关系图上的结构一致性损失，L_hier 为层次分类损失，L_reg 为常规正则项。各项权重的具体取值拟在后续研究中结合实验结果调整。

语义回溯方面，拟通过注意力权重将全局层预测映射回器官层与病灶层，再映射到报告中对应的描述片段，形成可核验的预测依据。

### （4）跨中心验证

项目拟在公开数据集与可用外部数据上开展验证。内部测试考察同分布条件下的性能，外部测试考察跨机构条件下的性能衰减，并分析衰减在语义层级中的分布：若衰减主要出现在病灶层，说明视觉识别受成像条件影响较大；若主要出现在器官层，说明区域定位存在偏差；若出现在全局层，则可能与类别体系差异有关。据此调整对齐策略与归一化方案。

## 2 项目创新性

本项目围绕报告弱监督医学图像分类中"报告语义粒度混杂、局部匹配关系缺失、分类依据不可追溯"等问题，将多粒度解析、关系图建模与层次分类进行协同设计。与仅改进网络结构或更换预训练数据的方法相比，本项目更关注监督信号的组织方式和匹配关系的显式刻画。创新性主要体现在以下三个方面。

（1）提出报告语义的三级粒度划分框架。本项目将"细粒度"从笼统的局部匹配推进到具有临床语义层级的显式结构，使全局印象、器官状态和病灶征象分处不同层级并保持从属关系。该设计使对齐过程可解释、错误来源可定位，也便于在层级之间传递监督以缓解长尾问题。

（2）引入匹配关系图建模局部匹配间的语义关联。现有方法多在逐对匹配后直接池化，本项目将匹配视为节点，以解剖邻近性与病理共现性构造边，通过图推理聚合相关证据。该设计突破了简单池化聚合的局限，为相似征象的消歧提供了结构依据。

（3）设计层次化分类与语义回溯机制。本项目使分类结果能够定位到具体的报告描述片段和图像区域，而非仅输出类别标签。该设计提升了预测结果的可核验性，也为分析跨中心性能衰减提供了层级化的诊断工具。

## 3 可行性分析

报告弱监督医学图像分类已有较为明确的研究基础。CLIP 范式在医学领域的适配研究积累了较多经验，细粒度对齐与层次分类也各有代表性工作，本项目在此基础上开展组合与改进，不需要从零构建全新范式，技术风险总体可控。

在数据条件方面，MIMIC-CXR、CheXpert、NIH ChestX-ray14 等公开数据集提供图像与报告配对数据，其中 MIMIC-CXR 报告结构相对完整，适合开展语义解析实验；CheXpert 与 NIH ChestX-ray14 类别体系清晰，适合开展分类与跨数据集验证。这些数据可直接用于预训练与评测，不依赖自建标注。

在方法实现方面，报告解析可基于开源大语言模型完成，采用提示工程与少量示例的方式即可获得可用抽取效果，不要求模型微调。双编码器对齐、对比学习和图推理均为成熟技术，已有大量开源实现可供参考。层次分类头只需在现有分类结构上调整输出组织方式，无需重新设计网络。各模块既可独立验证，也可在统一框架下联合优化。

在算力条件方面，项目拟采用参数高效微调策略降低训练开销，图像侧使用中等规模视觉主干，文本侧解析与编码采用推理方式完成，不涉及大规模模型训练。通过固定长度的图像区域采样和分批处理，可将显存占用控制在实验室常规 GPU 条件可承受的范围内。

在评价方面，分类任务可计算各类别的准确率、F1 值和 AUC；对齐质量可通过区域—文本匹配的定位精度和注意力图与报告提及区域的吻合程度评价；跨中心验证可通过留一中心交叉验证和外部数据集测试完成。相关评价方法较为成熟，能够为研究目标实现提供客观依据。

需要说明的是，项目名称中的"细粒度对齐"在 18 个月周期内不宜承诺覆盖所有模态和全部疾病类别。项目拟以胸部 X 线作为主要验证对象，完成解析、对齐、关系图与层次分类的完整链路验证，并根据进展向 CT 或病理模态开展一项扩展实验。该设计既能够体现方法的跨模态适应能力，也可以合理控制工作量。

在风险应对方面，报告解析质量可能受模板多样性影响，拟通过人工抽检定位问题类型并迭代提示模板；关系图的边构造依赖先验知识，拟在实验中对比不同构造方式的效果；跨中心数据获取存在不确定性，拟以公开数据集的跨数据集实验作为替代方案完成泛化验证。

申请人前期已围绕医学视觉—语言预训练、细粒度对齐和层次分类方向开展文献调研，精读了 MedFILIP、ECAMP、MG-3D 和 Inter-Matching Relation Modeling 等代表性工作，对报告监督的建模思路和主要难点有较清楚的认识，具备深度学习模型实现、训练和实验分析的基础条件。指导教师能够在问题凝练、方案设计和论文撰写方面提供指导。

综上，本项目具有明确的数据基础、理论支撑和技术路线。通过以胸部 X 线为主要对象、逐步向其他模态扩展，并合理控制关系图与层次分类的复杂度，在 18 个月内完成方法开发、实验验证和论文投稿具有较好的可行性。
