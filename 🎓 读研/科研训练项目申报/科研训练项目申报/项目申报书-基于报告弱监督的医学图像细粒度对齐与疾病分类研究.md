# 2026 级研究生科研训练计划项目申报

## 项目名称

**基于报告弱监督的医学图像细粒度对齐与疾病分类研究**

---

## 一、立项依据与研究意义

### 1.1 研究背景

医学图像分类是计算机辅助诊断的核心任务，但深度学习模型长期受制于**高质量标注的稀缺性**。像素级和病灶级标注需要专科医师逐例参与，成本高、周期长、难以规模化。

与之相对，**影像报告是临床工作中天然产生的免费监督信号**——每一位患者做影像检查都会产出一份报告，报告中明确写有病灶位置、性质、程度等诊断信息。如何利用海量"图像—报告"配对数据替代人工标注，是近年来医学人工智能领域最受关注的方向之一。

### 1.2 现有方法的局限

基于报告弱监督的视觉语言预训练（如 CLIP 范式的医学变体）已在多个模态上取得进展，但仍存在三方面关键问题：

**（1）报告信息"又多又杂"，粗粒度对齐失效**
一份影像报告通常包含多个解剖部位、多种征象，且夹杂模板化描述与阴性表述。将整份报告与整幅图像做全局对比学习，会导致**多病混淆**与**假阴性**——同类型病变被错判为不同类，同一条记录的不同表述被当作互斥样本。

**（2）病名抽取式方法丢失上下文**
为规避上述问题，部分方法（如病名派路线）改为抽取结构化病名作为标签。但这一做法丢弃了病灶位置、程度等关键属性，且对**训练集中未出现的新疾病**完全失效。

**（3）细粒度语义与视觉特征的对应关系未被充分建模**
现有方法多通过池化等简单操作聚合局部匹配关系，忽视了局部匹配之间的**语义关联**与**层次结构**，导致表征的可解释性与跨中心泛化能力不足。

### 1.3 研究意义

**理论意义**：探索报告监督信号中"语义粒度"与"视觉证据"之间的显式对应关系，为弱监督跨模态表征学习提供新的建模思路。

**应用价值**：降低医学图像分类模型对人工标注的依赖，提升模型在标注稀缺病种、罕见病、多中心场景下的可用性，为基层医疗机构的辅助诊断提供可行路径。

## 二、国内外研究现状

### 2.1 医学图像—文本预训练的主流范式

CLIP 范式引入文本监督后，在医学影像领域迅速铺开。近期综述（*CLIP in medical imaging: A survey*, Medical Image Analysis 2025）系统梳理了这一方向的两条主线：**精化式 CLIP 预训练**与**CLIP 驱动的下游应用**。

代表性工作包括：
- **病理方向**：CONCH、TITAN 等在全切片级别构建图文基础模型，TITAN 使用 335,645 张全切片图像完成视觉自监督与图文对齐联合预训练（*Nat Med* 2025）；MUSK 利用 5000 万张病理图像与十亿级病理文本，在**未配对**数据上完成多模态统一掩码建模（*Nature* 2025）
- **眼科方向**：RetiZero 引入 400 余种眼底疾病知识，在 341,896 张眼底图像上预训练，零样本场景下 Top-5 准确率达 0.843（*Nat Commun* 2025）；EyeCLIP 覆盖 11 种模态 277 万张图像（*npj Digit Med* 2025）
- **三维方向**：Merlin 面向腹部 CT，构建 3D 视觉语言模型，采用多阶段预训练联合体数据、电子病历与报告（*Nature* 2026）

### 2.2 细粒度与实体级对齐方法

针对粗粒度对齐的缺陷，近期工作转向更精细的语义切分：

- **MedFILIP**（*IEEE JBHI* 2025）提出基于大语言模型的信息抽取器，从报告中解耦疾病细节，并通过对比学习引入医学图像特有关联
- **ECAMP**（*Medical Image Analysis* 2025）以**实体为中心**蒸馏报告的上下文信息，兼顾报告的语义复杂度与类别不平衡
- **MG-3D**（*Medical Image Analysis* 2026）提出多粒度知识增强的 3D 视觉语言预训练，利用报告作为监督信号构建 3D 基础模型
- **Inter-Matching Relation Modeling**（*IEEE TMI* 2025）指出局部匹配间的**内在关系**被简单池化所忽略，提出匹配关系建模
- **AFLoc**（*Nat Biomed Eng* 2026）基于多层级语义结构的对比学习，对齐多粒度医学概念与图像特征，实现免标注的病灶定位

### 2.3 层次分类与长尾问题

- **Dual-geometry image–text learning**（*Medical Image Analysis* 2026）面向医学层次化图像分类，从双几何角度建模图文关系
- **PathPT**（*Nat Commun* 2026）针对罕见癌亚型，通过空间感知视觉聚合与任务特定提示调优，将切片级监督转化为细粒度信号
- **CXR-LT 2026**（*Medical Image Analysis* 2027 卷）设立多中心长尾与零样本胸片分类的标准化评测

### 2.4 现状评述

现有工作已证明报告监督的有效性，但仍存在明显空白：

1. **粒度划分缺乏统一框架**——当前方法多采用"报告→实体"或"图像→区域"的固定粒度，缺少按临床语义层级自适应划分的机制
2. **局部匹配关系未被显式建模**——多数方法止步于逐对相似度，未考虑实体之间的解剖与病理关联
3. **跨中心泛化验证不足**——现有模型在外部队列上的稳健性存在系统性缺陷（*PathoROB*, *Nat Commun* 2026 已证实 20 个病理基础模型均存在鲁棒性缺口）

本项目正是针对上述空白展开。

## 三、研究内容

### 3.1 报告语义的多粒度结构化解析

**目标**：将非结构化影像报告解析为具有临床语义层级的结构化表示。

**内容**：
- 设计提示工程驱动的大语言模型抽取流程，从报告中解耦出「解剖部位—征象—属性（位置/程度/性质）」三元组
- 建立报告的语义粒度层级：**全局（检查类型）→ 器官级（解剖区域）→ 病灶级（具体征象）**
- 针对报告中的模板化表述与阴性描述设计过滤与降权机制

**对标工作**：MedFILIP 的信息抽取器、ECAMP 的实体中心蒸馏

### 3.2 细粒度图文对齐与局部关系建模

**目标**：在病灶级别建立图像区域与报告语义单元的对应关系，并显式建模匹配间关系。

**内容**：
- 构建区域级—语义级对比学习目标，替代整图—整报告式的全局对齐
- 引入**匹配关系图**：将局部匹配作为节点，以解剖邻近性与病理共现性作为边，通过图推理聚合证据
- 设计软标签机制，缓解同一语义的多表述导致的假阴性问题

**对标工作**：Inter-Matching Relation Modeling（TMI 2025）、AFLoc（Nat Biomed Eng 2026）

### 3.3 层次化分类器设计与跨中心验证

**目标**：将细粒度表征映射到疾病分类任务，并在多中心数据上验证稳健性。

**内容**：
- 设计层次化分类头，使预测结果可回溯至具体的报告语义单元，提供分类依据
- 在公有数据集与自建多中心数据上开展外部验证，评估跨中心性能衰减
- 与 CLIP 范式基线、病名抽取式方法进行系统对比

**对标工作**：Dual-geometry 层次分类（MedIA 2026）、PathoROB 鲁棒性评估框架（Nat Commun 2026）

## 四、技术路线

```
原始影像 + 配对报告
        │
        ├─→ [3.1] 报告结构化解析
        │       LLM 抽取 → 三元组 → 三级粒度语义单元
        │
        └─→ 图像编码器（预训练 ViT / 3D 编码器）
                │
                ↓
        [3.2] 细粒度对齐模块
                │  区域特征 ←→ 语义单元特征
                │  匹配关系图推理
                │  软标签对比损失
                ↓
        [3.3] 层次化分类头
                │  病灶级预测 → 器官级聚合 → 全局诊断
                ↓
        多中心外部验证 + 消融实验
```

**关键实验设计**：
- 消融：全局对齐 vs 细粒度对齐；无关系图 vs 有关系图；硬标签 vs 软标签
- 泛化：留一中心交叉验证、跨模态迁移
- 可解释性：注意力可视化与报告语义单元的对应关系

---

## 五、创新点

1. **提出报告语义的三级粒度划分框架**，将"细粒度"从笼统的"局部匹配"推进到具有临床语义层级的显式结构，使对齐过程可解释、可追溯

2. **引入匹配关系图建模局部匹配间的语义关联**，突破现有方法依赖简单池化聚合的局限，显式刻画解剖邻近性与病理共现性

3. **设计层次化分类与语义回溯机制**，使分类结果能够定位到具体的报告描述片段，提升临床可信度

## 八、可行性分析

**数据基础**：MIMIC-CXR、CheXpert、NIH ChestX-ray14 等公开图文数据集可直接使用；自建多中心数据可通过合作医院获取。

**技术基础**：已具备医学视觉语言预训练方向的文献积累与代码复现经验，已精读 MedFILIP、M3GCD 等相关工作。

**算力条件**：可视实验室现有算力条件，采用参数高效微调（LoRA / Prompt Tuning）降低训练成本。
