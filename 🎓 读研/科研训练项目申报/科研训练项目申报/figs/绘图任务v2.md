上一版用 matplotlib 画出来的两张图，用户评价是「**一看就是 AI 画的**」。这是明确的否定反馈。

现在用户给了 4 张这类图，要求**照着这些图的感觉重画**。

## 从这 4 张图提取的视觉特征（必须照做）

### 1. 结构：不是「五个等大框排一排」
参考图的核心特征是**层级 + 主次**：
- 总览图（dfbad497）：三列纵向堆叠，每列三行，**用 ⇒ 双线箭头跨列连接**，左右两列文字量大于中间
- 细节图（dfede7ba/9b8bfddc/6560d13d）：有明确的主体（视频帧/图像）占据中部大面积，模块和损失符号环绕四周

### 2. 形状：方框少、直角多、圆角小
- **不要大圆角**（上一版 rounding_size=0.12 太大）。参考图里框的圆角很小或干脆是直角
- 大量元素**不用框**：纯文字、下划线、括号、箭头直接连
- 虚线框表示「可选/扩展/无标注分支」

### 3. 配色：黑白灰为主 + 少量彩色强调
- 主体：**黑线 + 白底 + 灰阶**
- 彩色只用于**强调项**（损失项、关键模块），且饱和度低
- 上一版「每个色带平均分配颜色」的做法**彻底抛弃**

### 4. 文字：小、密、贴着元素走
- 字号比上一版更小（6~8pt），字距更紧
- 文字**不居中放在框里**，而是标在箭头旁、公式下方、模块上方
- 公式（L_sup、L_semi、L_total 等）直接写，带下标，不另设图例

### 5. 元素：用真实图形的示意，不用纯色块
- 视频/图像类用**缩略图**（可裁参考图里的小图，或画极简线稿：矩形+内部线条示意）
- 网格矩阵用密集细线格
- 箭头用直角折线，线宽细（0.8~1.0pt）

## 需要重画的两张

### 图 1：总体技术路线（模仿 ref_dfbad497 的三列式）

**结构改为三列：**
- **左列「挑战」**（三行）：
  1. 报告语义冗余、粒度失配
  2. 局部匹配关系未被显式建模
  3. 分类依据不可回溯、跨数据集性能衰减
- **中列「研究内容」**（三行，每行是实心强调框，比左右列更醒目）：
  1. 基于大语言模型的报告语义多粒度结构化解析（研究内容 2.1）
  2. 基于区域级对比学习与匹配关系图的细粒度对齐（研究内容 2.2）
  3. 基于层次化分类头的可回溯分类与跨数据集验证（研究内容 2.3）
- **右列「预期效果」**（三行，小字）：
  1. 语义单元抽取稳定、模板与阴性表述可控
  2. 病灶级图文对应显式建模、相似征象可消歧
  3. 预测可回溯到报告片段、跨数据集性能衰减可分析

**连接**：左 → 中 用 **⇒ 双向粗箭头**（参考图那样，双线箭头），中 → 右 用细箭头。
**底部**：一条横向跨度条，写「胸部 X 线（主要验证）→ CT / 病理（条件允许时扩展）」

**图幅**：宽 16cm × 高 8cm。图题「图 1  总体技术路线」在下方居中。

## 硬性要求

1. **禁止**：大圆角矩形、渐变、阴影、3D、emoji、平均分配的彩虹色带、图例框
2. **优先**：直角、细线、黑白灰、少量强调色（建议只用 #2F5597 深蓝 + #C00000 暗红用于损失项）
3. 中文用 **Noto Serif CJK SC**（参考图是宋体感觉，不是黑体）——如果不好用就用 Noto Sans CJK SC 但字号收紧
4. 英文/公式用 **DejaVu Serif** 或 STIX（衬线，配合中文宋体）
5. 用 Python + matplotlib 绘制，**但可以自由用 patches / Path / annotate，不必拘泥于 box() 封装**
6. 输出 PNG 300dpi + PDF 矢量，覆盖 `图1-总体技术路线.png/.pdf`、`图2-模型结构与信息流.png/.pdf`
7. **画完自查**：
   - 对照参考图问自己：这张图如果和 ref_dfbad497 并排放，风格一致吗？
   - 文字有没有出框、重叠
   - 缩到 A4 打印大小时还看得清吗
   - 有没有「模板感」
