## 🔴 内容：严格按正文（不得自编）

正文原文关键要素（三、1（2）（3）节）：

### 输入侧
- 图像：胸部 X 线图像（可画 2~3 个极简缩略图示意，或一个带「…」的图像序列）
- 文本：原始报告 R_i

### 图像支路
- 预训练视觉主干 → 区域特征 **v_j**（j = 1..J）
- 投影函数 **φ**

### 文本支路
- 开源大语言模型解析（提示模板 + 少量示例）→ 语义单元 **t_k**（k = 1..K）
- 三级：全局层 / 器官层 / 病灶层
- 语言编码器 → 投影函数 **ψ**

### 匹配
- 匹配分数：**s_jk = ⟨φ(v_j), ψ(t_k)⟩ / τ**（τ 为温度系数）
- 软标签机制（语义相近但表述不同 → 部分正样本权重，缓解假阴性）
- 损失：**L_align**（区域—语义对比损失）+ **L_soft**（软标签正则项）

### 关系图
- **G = (V, E)**，节点 V = 各局部匹配
- 边 E：**解剖邻近性** + **病理共现性**
- 节点更新：**h_v^(l+1) = σ( W^(l) · AGG( { h_u^(l) | u ∈ N(v) } ∪ { h_v^(l) } ) )**
- 损失：**L_graph**（关系图上的结构一致性损失）

### 层次化分类
- 逐级：**病灶层 → 器官层 → 全局层**
- 每一级与报告对应层级语义单元建立监督
- 损失：**L_hier**（层次分类损失）

### 语义回溯
- 注意力权重：全局层预测 → 器官层 → 病灶层 → **报告中对应的描述片段**

### 总损失（必须完整写全五项！）
```
L_total = L_align + λ1·L_soft + λ2·L_graph + λ3·L_hier + λ4·L_reg
```
L_reg = 常规正则项
