## 项目背景
项目名称：**基于报告弱监督的医学图像细粒度对齐与疾病分类**
申请人：孟浩楠｜硕士研究生｜计算机科学与技术｜研究方向 AI+医疗
周期：2026.9—2029.3（30 个月）

正文核心逻辑（来自申报书"三、研究思路与方法"）：
总体技术思路为 **报告结构化解析 → 语义单元构建 → 区域级对比学习 → 匹配关系图推理 → 层次化分类 → 跨数据集验证**。

## 需要画的两张图

### 图 1：总体技术路线图（对应正文"图 1 总体技术路线"）

放在正文"1 研究思路和方法"一节开头，用于一眼讲清整个研究链路和三个阶段任务的对应关系。

**必须包含的内容（不得自行增删核心节点）：**

**输入层（底部/左侧起点）**
- 胸部 X 线图像（Chest X-ray）
- 影像报告（自由文本，如 "There is a small left pleural effusion..."）

**处理链（自左向右，五个主模块）**
1. **报告语义结构化解析**（大语言模型 + 提示模板 + 少样本示例）
   输出三级语义单元：全局层 / 器官层 / 病灶层；病灶层含 征象名称、位置、程度、性质
   附：模板化表述与阴性意见过滤
2. **细粒度图文对齐**（双编码器 + 区域级对比学习 + 软标签机制）
   图像侧：预训练视觉主干 → 区域特征 v_j
   文本侧：语义单元编码 → t_k
   匹配分数 s_jk，区域—语义对比损失
3. **匹配关系图建模**（图神经网络推理）
   节点=局部匹配；边=解剖邻近性 + 病理共现性；聚合更新局部表征
4. **层次化分类与语义回溯**
   病灶层 → 器官层 → 全局层 逐级预测；预测结果可回溯到具体报告描述片段
5. **跨数据集验证**
   MIMIC-CXR / CheXpert / NIH ChestX-ray14

**右侧输出**
- 疾病类别预测（多标签）
- 可回溯的证据片段（高亮对应报告句子）
- 跨数据集性能与语义层级衰减分析

**图示要求：**
- 三个阶段任务要有可视分组（对应正文 2.1 / 2.2 / 2.3 三项研究内容），用不同底色区分
- 主链路用箭头串起来，箭头方向清晰（建议自左向右、必要时可折行）
- 关键公式符号（v_j、t_k、s_jk、G=(V,E)）可在模块内小字标注，不要喧宾夺主
- 图幅建议 **宽 16cm × 高 8~9cm**（A4 正文页内可完整放下，不跨页）

### 图 2：模型结构与信息流（对应正文"图 2 模型结构与信息流"）

放在正文"（2）细粒度图文对齐与匹配关系图建模"小节，讲清模型内部数据怎么流。

**必须包含：**

- **左侧图像支路**：X 线图像 → 视觉主干（ViT/ResNet，中等规模）→ 区域特征 {v_1...v_J}
- **右侧文本支路**：报告 → LLM 结构化解析 → 语义单元 {t_1...t_K}（含层级标签 l_k 与属性 a_k）
- **中部对齐层**：投影 φ(·)、ψ(·) → 匹配矩阵 S（J×K）→ 区域—语义对比损失 L_align + 软标签正则 L_soft
- **关系图模块**：由匹配矩阵构建图 G=(V,E)，V 为局部匹配，E 由解剖邻近性/病理共现性构造 → 图聚合 AGG → 更新后的局部表征
- **层次分类头**：病灶层 → 器官层 → 全局层 三级输出
- **底部总损失**：L = L_align + L_soft + L_cls（三个损失加权求和）

**图示要求：**
- 数据维度变化要在箭头旁标出（如 J×K 矩阵用网格示意）
- 张量/矩阵用小型网格图形表示，比纯文字更直观
- 图幅建议 **宽 15cm × 高 7~8cm**
