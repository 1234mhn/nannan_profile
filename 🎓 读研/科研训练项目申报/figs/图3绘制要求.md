### 数据来源（正文「可行性分析」明确列的）
- **MIMIC-CXR**：报告结构相对完整 → **适合语义解析实验**

### 划分
- 训练集 / 验证集 / **内部测试**（同分布）
- **外部测试**（跨数据集）

### 评价指标（正文「可行性分析 → 在评价方面」明确写的）
1. **分类任务**：各类别的**准确率、F1 值、AUC**
2. **对齐质量**：区域—文本匹配的**定位精度**、注意力图与报告提及区域的**吻合程度**
3. **跨数据集**：跨数据集测试 + 外部数据集测试

### 层级衰减分析（正文 2.4 和 (4) 跨数据集验证 明确写的）
正文原句：「分析衰减在语义层级中的分布：若衰减主要出现在**病灶层**，说明视觉识别受成像条件影响较大；若主要出现在**器官层**，说明区域定位存在偏差；若出现在**全局层**，则可能与类别体系差异有关。据此调整对齐策略与归一化方案。」

→ 图的最后一步要体现这个**三层归因**：
- 病灶层衰减 → 视觉识别受成像条件影响
- 器官层衰减 → 区域定位存在偏差
- 全局层衰减 → 类别体系差异
- **→ 据此调整对齐策略与归一化方案**（闭环，可画回指箭头）


## 布局建议（16cm × 8cm）

按流程横向推进，最后一步做层级归因：

```
┌──────────────────────────────────────────────────────────────────┐
│  数据集           划分              测试            评价            │
│                                                                  │
│  MIMIC-CXR ──┐                                                    │
│  (语义解析)   │   ┌─────────┐   ┌──────────┐   ┌────────────┐    │
│  CheXpert ──┼──→│ 训练集   │──→│ 内部测试  │──→│ 分类：       │    │
│  (分类)      │   │ 验证集   │   │ (同分布)  │   │ 准确率/F1/AUC│    │
│  NIH ──────┘   └─────────┘   └──────────┘   │ 对齐：       │    │
│  (跨数据集)              │                    │ 定位精度/    │    │
│                          ↓                    │ 注意力吻合度 │    │
│                    ┌──────────┐              └────────────┘    │
│                    │ 外部测试  │                     │          │
│                    │(跨数据集) │                     ↓          │
│                    └──────────┘              ┌────────────────┐ │
│                                              │ 层级衰减归因     │ │
│                                              │ 病灶层→成像条件  │ │
│                                              │ 器官层→区域定位  │ │
│                                              │ 全局层→类别体系  │ │
│                                              └────────────────┘ │
│                                                      │           │
│                                    调整对齐策略与归一化方案 ←──┘ │
└──────────────────────────────────────────────────────────────────┘
```

也可以做成**上下两层**：上层「数据→划分→测试」流程，下层「评价指标 + 层级归因」并列。
