## 诊断：上一版错在哪

上一版画成了「挑战 → 研究内容 → 预期效果」三列式**论证结构图**（那是「主要研究内容」图该有的样子，对应参考图 ref_dfbad497）。但正文里这张图叫**「图 1 总体技术路线」**，放在「1 研究思路和方法」一节开头。

技术路线图 = **数据是怎么被一步步加工的流程图**，必须体现：
- 数据从哪进（输入）
- 依次经过哪些技术处理步骤（主链，箭头单向推进）
- 每步的输入输出形态变化
- 最后产出什么

**三列论证结构 ≠ 技术路线。必须换成纵向或横向的流程主链。**

## 硬性修改要求

### 1. 删除所有下划线
- 列标题下划线（`line(...7.40...)`）—— 删
- 「挑战一/二/三」标题下划线 —— 删

### 2. 改成真正的流程链结构

**推荐：横向主链 + 上方阶段标注 + 下方数据形态**

```
┌──────────────────────────────────────────────────────────────┐
│  [阶段一]        [阶段二]         [阶段三]                     │  ← 顶部：研究阶段色带（浅色，仅作背景）
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ①输入 ─→ ②处理 ─→ ③处理 ─→ ④处理 ─→ ⑤处理 ─→ ⑥输出      │  ← 主链：横向流程，单向箭头
│                                                              │
├──────────────────────────────────────────────────────────────┤
│  数据形态：  图像+报告 → 三级语义单元 → 区域-单元匹配 → ...   │  ← 底部：每步的数据形态变化
└──────────────────────────────────────────────────────────────┘
```

### 3. 具体主链（严格按正文「1 研究思路和方法」原文）

正文原句：**「报告结构化解析 → 语义单元构建 → 区域级对比学习 → 匹配关系图推理 → 层次化分类 → 跨数据集验证」**

按这 6 步做横向主链，每步一个节点：

| 步骤 | 节点名 | 下方小字（技术手段） | 输入→输出形态 |
|:--|:--|:--|:--|
| ① | 图像—报告数据 | MIMIC-CXR / CheXpert / NIH | 原始数据 |
| ② | 报告结构化解析 | 大语言模型 + 提示模板 + 少样本示例 | 自由文本 → 三级语义单元 |
| ③ | 语义单元构建 | 全局层 / 器官层 / 病灶层 | 三级层级结构 |
| ④ | 区域级对比学习 | 双编码器 + 软标签机制 | (图像, 文本) → 匹配分数 |
| ⑤ | 匹配关系图推理 | 图神经网络，解剖邻近性 + 病理共现性 | 匹配 → 关系图 → 更新表征 |
| ⑥ | 层次化分类 | 病灶层→器官层→全局层 逐级预测 | 表征 → 疾病类别 + 回溯片段 |
| ⑦ | 跨数据集验证 | 跨数据集性能与语义层级衰减分析 | 模型 → 性能评估 |

（就是 7 个节点：输入 1 + 处理 5 + 验证 1）
