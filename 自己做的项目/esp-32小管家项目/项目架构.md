# 项目架构

## 四层结构

### 1. 实体层

- ESP32-S3 开发板
- 麦克风
- 扬声器
- RGB 状态灯
- 实体确认按钮
- 后续增加摄像头

### 2. 通信层

- ESP32 通过 Wi-Fi 联网
- 首选 HTTPS 或 WebSocket
- 不直接暴露 OpenClaw 管理端口
- 使用独立设备密钥验证
- 基础连通性已验证：开发板通过手机热点联网，DNS 解析成功，普通 HTTP 请求返回 200
- HTTPS Webhook 使用 TLS 根证书校验；测试程序已准备，板端编译、烧录和服务器收件确认待完成

### 3. 智能层

- 云服务器运行 OpenClaw
- OpenClaw 作为总控 Agent
- 多个 Agent 分工处理记录、搜索、总结和执行

### 4. 数据层

- 保存原始音频、图片和视频
- 保存语音转写文字
- 保存摘要、日期、项目和标签
- 后续建立可检索知识库

## 典型流程

```text
语音输入
→ ESP32 录音
→ 云服务器接收
→ 语音识别
→ OpenClaw 分析
→ 保存原始资料和整理结果
→ 语音回复
```

## Mac 控制流程

```text
ESP32
→ 云端 OpenClaw
→ 安全的 Mac 本地执行器
→ 打开应用、文件或执行允许的任务
→ 返回执行结果
```
