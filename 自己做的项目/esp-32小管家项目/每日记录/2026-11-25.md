# 2026-11-25 项目记录

## 完成 ESP32-S3 编译与烧录验证

- 终端显示 `Platform Tools Installed`。在 Arduino IDE 选择 `ESP32 Arduino (in Sketchbook)` 中的 `ESP32S3 Dev Module`，选择开发板对应的 USB 串口，空白程序和串口测试程序均编译通过。
- 开启详细上传日志后，确认 esptool 能识别 ESP32-S3。上传速度切到 `921600` 后，芯片在检查闪存时停止响应，IDE 报 `exit status 2`。
- 将 **Tools → Upload Speed** 降到 `115200` 后烧录成功。串口监视器设为 `115200 baud`，确认板子每秒打印一行 `Hello ESP32-S3`。

测试程序见 [serial_test.ino](../serial_test/serial_test.ino)。后续继续验证 Wi-Fi 和 HTTPS 接入。
