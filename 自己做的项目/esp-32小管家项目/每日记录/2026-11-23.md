# 2026-11-23 项目记录

## 今天完成

### 1. 确认 OpenClaw 基础状态

- 腾讯云服务器系统：Ubuntu 24.04.4 LTS。
- OpenClaw 版本：2026.7.1-2。
- OpenClaw 通过 pnpm 安装，不是 Docker。
- 微信通道保持正常：`openclaw-weixin ON / OK`。
- Gateway 服务由 systemd 管理，运行正常。

### 2. 收紧 Gateway 监听范围

执行：

```bash
openclaw config set gateway.bind loopback
openclaw gateway restart
```

结果：

- Gateway 只监听本机 `127.0.0.1:8080`。
- 外部设备不能直接访问 OpenClaw 管理端口。
- 微信接口未受影响。

### 3. 开启 OpenClaw Webhook

配置了独立的 Webhook 密钥，并开启接口：

```bash
openclaw config set hooks.token "$(openssl rand -hex 32)"
openclaw config set hooks.enabled true
openclaw config set hooks.allowedAgentIds '["main"]'
```

安全措施：

- Webhook 使用独立密钥，不复用 Gateway 密钥。
- Webhook 只允许调用 `main` Agent。
- 密钥没有写入 GitHub，也没有上传到聊天记录。

### 4. 本机 Webhook 测试

测试地址：

```
http://127.0.0.1:8080/hooks/agent
```

返回：

```
HTTP/1.1 200 OK
{"ok":true,...}
```

说明 OpenClaw hooks 通道工作正常。

### 5. 配置域名和 HTTPS

新增子域名：

```
esp32.nannan2026.cn
```

域名解析到腾讯云服务器后，申请 Let's Encrypt 证书：

```
/etc/letsencrypt/live/esp32.nannan2026.cn/
```

证书有效期至 2027-02-21，并已设置自动续期。

### 6. 配置 Nginx 反向代理

Nginx 将：

```
https://esp32.nannan2026.cn/hooks/agent
```

转发到：

```
http://127.0.0.1:8080/hooks/agent
```

HTTPS 测试返回：

```
HTTP/2 200
{"ok":true,...}
```
