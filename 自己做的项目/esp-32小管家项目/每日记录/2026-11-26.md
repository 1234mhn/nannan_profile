# 2026-11-26 项目记录

## 打通 ESP32-S3 Wi-Fi 和基础网络访问

### 目标

让 ESP32-S3 通过 OPPO 手机热点联网，并确认网络可解析域名、访问外网。

### 操作与排查

- 确认开发板为 ESP32-S3，使用 Arduino IDE 2.3.11、`ESP32S3 Dev Module` 和 USB 串口，串口速率设为 `115200 baud`。
- 手机热点使用 2.4 GHz 和 WPA2-Personal。初始连接出现 `DISCONNECT_REASON=15`（握手超时），并曾返回连接失败。
- 重启开发板，在串口监视器中输入当时有效的热点密码后，ESP32-S3 成功连接。文档和代码均不保存热点密码。
- 上传网络检查程序，串口再次输入密码；程序依次检查 Wi-Fi 连接、DNS 解析和 HTTP 请求。

### 验证结果

- 串口输出 `WIFI_CONNECTED`，DHCP 分配到 IP 地址。
- RSSI 约 `-60 dBm`。
- 输出 `DNS_OK example.com`，域名解析成功。
- 输出 `HTTP_STATUS: 200`，普通 HTTP 外网请求成功。

## 完成 HTTPS Webhook 端到端测试

### 操作与排查

- 将带热点扫描与 Wi-Fi 断开原因输出的诊断版载入 Arduino IDE，编译并烧录到 ESP32-S3。
- 首次扫描输出 `TARGET_HOTSPOT_FOUND=NO`；随后输入热点密码后仍成功连上 Wi-Fi，串口输出 `WIFI_CONNECTED`。
- NTP 时间同步成功，串口输出 `NTP_TIME_SYNCED`。
- 从腾讯云 OpenClaw 配置中使用专用 Hook Token；token 只在串口运行时输入，未写入草图或项目记录。
- ESP32 发出 HTTPS POST 后，串口输出 `HTTP_STATUS: 200`，响应包含 `"ok":true`。

### 验证结果

- ESP32-S3 已通过 TLS 证书验证并成功访问 HTTPS Webhook。
- OpenClaw 返回成功响应，表示请求已被服务端接受。
- 测试 payload 设置 `deliver:false`，因此此测试不要求向聊天渠道额外投递回复。
- 热点密码、Hook Token、完整公网 IP 和实际 runId 均未记录。
