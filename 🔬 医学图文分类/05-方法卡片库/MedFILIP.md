## 一句话做了什么
用 LLM 把报告拆成「疾病/位置/程度」，把疾病名翻译成"视觉上长什么样"，再用文本相似度替代 0/1 标签，分别与图像对齐。

## 质疑了什么
- **对齐粒度太粗**（对应 [[04-痛点清单#C1. 整图对整报告，属性被"平均掉"]]）：
  整份报告压成一个向量，疾病类别 / 位置 / 形态 / 程度四样信息被 **averaged（平均掉）**。
  作者用词是 averaged 而不是 lost —— 因为"平均掉"更麻烦：察觉不到、会污染其他信息、想修都无从下手。
- **文本非结构化**（对应 [[04-痛点清单#F1. 报告是非结构化的自然语言]]）。
- **缺视觉描述**：病名是医学名词，图像里只有像素，中间没有桥。
- **0/1 硬标签造假阴性**（对应 [[04-痛点清单#B1. 用 0/1 配对标签会造出假阴性]]）。
- 同时质疑"病名派"（MedKLIP）：丢上下文/子类、认不出没见过的新病。

## 核心方法（分点）

### 模块一：GPT-IE（GPT Information Extraction）
- 用 **GPT-3.5-Turbo** 读报告，按固定模板抽成结构化三元组：
  `{severity, location, category} = f_IE(report + prompt)`
- 效果：自然语言 → 规整三元组，后面才好分别对齐。
- **严格说不是三个平等字段**，而是「1 个主键（category）+ 2 个可选属性」：
  - 缺 severity / location 保留；
  - 缺 category **删除**（原文明确）。
- 1 对 1 → 1 对多（一条报告可抽出多个实体）。

### 模块二：IKI（Image Knowledge Injection）
- `T_e = Dict(T_f[categories])`：病名 → 视觉描述。
- 例：「肺炎」→ **「肺部出现斑片状或融合的白色区域」**，再拿这段描述去和图像对齐。
- 为什么有效：①"斑片状白色区域"是图像里真能看到的东西；②碰上没见过的新病（如 COVID-19），
  只要视觉描述写得出来，模型就能认 —— **因为它学的是"视觉长什么样"，不是死记病名**。
- 与 MedKLIP 的对照：不是让模型分辨"肺炎"和"气胸"两个词，而是分辨两段描述出来的图。

### 模块三：SSM（Semantic Similarity Matrix）
- `M×M` 文本相似度矩阵 → 逐列取 max → `N×M` 标签矩阵 `s`。
- 原文表述："the maximum values of **each column** in a sub-matrix of size `cᵢ × M`"
  → 横向看是压行（`cᵢ` 行 → 1 行），纵向看是每列取最大，**同一件事**。
- 不用 mean 的原因：避免弱匹配污染 + 防止强匹配被削弱。
- 损失：`L = MSE + CE`。
- 本质：从"这是不是一对"（硬标签）变成"这一对有多像"（软标签 0~1 回归）。

### 流水线关系（易错点）
> GPT-IE 与 SSM 是**流水线上下游**，不是并列各治一个毛病。
> 原文 Fig.2 图注是按**处理对象**组织的，不是按 Fig.1 的问题编号。
> （这是 memory/2026-10-27 记录的一次纠错：曾编造"4 问题对 3 模块"的对应关系，被用户当场纠正。）

### 先验知识 ≠ Dictionary
- **Dict 是载体（抽屉），先验知识是内容（抽屉里的东西）**。
- 原文 Related Work 分三类：`anatomical, pathological, and imaging correlates`。
- 三处注入：IKI 的 Dict（显式）+ SSM 的 `E_sim`（隐式）+ GPT-3.5（隐式）。

## 可借鉴的点
1. **"翻译"这一步最值得偷**：不拿类别名直接对图，先把类别名翻译成图像语言。这个 trick 与模型无关，可以搬到任何对比学习框架里。
2. **三元组设计的取舍原则**：「缺 severity/location 保留，缺 category 删除」—— 主键缺失就没意义，属性缺失仍可用。设计自己的结构时照这个思路。
3. **SSM 用 max 不用 mean**：避免弱匹配污染、防止强匹配被削弱。这个细节在做多维软标签时直接影响结果。
4. **消融做成阶梯**（Baseline → +Entity → +FG → +IKI → +SSM），一条线讲清楚每个模块值多少，讲组会时极好讲。

## 局限
**作者自己承认：**
- ChestX-ray14 上输给 MedKLIP（85.67 vs **86.19**）。

**我读出来的（来源 memory/2026-10-27 讲解记录）：**
- **尺寸/数量信息丢失**：三元组里没有 size / count。
- **形态被推给静态 Dictionary**：形态由 IKI 的字典决定，缺动态建模。
- **多灶性（multiple lesions）无法表达**：三元组结构天生只能表达"一个病灶在哪、多重"。
- **抽取器误差会传播**：GPT-3.5 抽错 → SSM 标签错 → 对齐错，未见误差分析。
- **否定/不确定未专门处理**：「未见气胸」这类表述在三元组里没有显式位置 → 见 [[04-痛点清单#F2. 报告里存在否定与不确定性表述]]。
