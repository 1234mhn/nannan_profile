## 一句话做了什么
**不改 CLIP 的双塔与对比损失**，在图文特征的对齐网络上插入一个由 core-periphery 图结构约束的**共享 MLP 辅助网络**；目标是**保住/提升 CLIP 在医学域的零样本能力**，并顺带获得「哪些区域与疾病相关」的**可解释性**。图结构上：核心节点连所有节点、外围节点只连核心、外围之间不连。

> 🔴 旧版本只写「换掉全连接层」，漏掉了**任务定位**。CP-CLIP 不是「纯特征对齐方法」，它是**零样本医学图像分析**方法（zero-shot + critical region detection 两条任务线）。2026-11-14 已修正。

## 任务定义（两条任务线，原文明确）

| 任务 | 原文表述 | 数据 |
|:--|:--|:--|
| **① 零样本分类** | zero-shot medical image prediction | **five public datasets**，覆盖不同疾病 |
| **② 关键区域检测 / 可解释性** | automatic identification of critical disease-related regions；excellent explanatory capability | 同上（定性 + 定量） |

> 为什么这条很关键：I2（给核心—外围建显式关系）最可能撞车的赛道，就是 CP-CLIP 自己的**第二条任务线**。改邻接矩阵这件事在它的谱系里已被用于「提高可解释性／关键区域定位」。所以 I2 必须明确回答：**我是要在零样本上赢，还是在可解释性上赢？** 否则审稿人第一个问题就是「你和它的 critical region detection 差别在哪」。

## 质疑了什么
- **质疑对齐粒度**（对应 [[04-痛点清单#C2. 按空间块切图，块里病灶和背景混着]]）：
  原生 CLIP 只在全局层级做图文对齐，而病灶占像素极低 → 语义粒度单一。
- 前人（GLoRIA 等，⚠️未建卡）"切细了，但没切干净"——按空间块切图，块里病灶和背景混着。
- CP-CLIP 的做法是把"主次分离"从**切图**搬到**网络内部连接结构**上。

## 核心方法（分点）

### 1. 编码器（未改）
- 预训练 **ResNet50**（图像）+ 预训练 **BERT**（文本）
- 投影头 `f_I` / `f_T` 输出到共同维度 P
- `u_I = E_I(I), u = f_I(u_I)`
- `u_T = E_T(T), t = f_T(u_T)`

### 2. CP 图生成（Eq.3，邻接矩阵）
- 节点分**核心**和**外围**两组：
  - 核心节点数 `n = N × p`
  - 外围节点数 `m = N × (1 − p)`
  - `p ∈ (0, 1]` 为**核心比（core ratio）**
- 邻接矩阵：
  ```
  A(i,j) = 1   若 i, j 都在核心，或 一核心一外围
  A(i,j) = 0   若 i, j 都在外围
  ```
- **p = 1.0 时退化为完全图，即普通全连接 MLP。**
- 一句话：**核心节点连所有节点，外围节点只连核心，外围之间不连。**

### 3. CP 图指导的 MLP（Eq.5）★ 本文唯一真正的创新点
```
Z^(r+1) = σ^(r) { (A ⊙ W^(r)) Z^(r) }
```
- 用邻接矩阵 A **逐元素乘**权重矩阵 W，把全连接改为按图连接。
- **创新全在 A 这一个符号上**：不该连的边直接归零，得到的是**结构化稀疏**，不是随机稀疏。
- 灵感来源：**脑网络**（core-periphery 结构）。

### 4. 共享权重 CP 网络（Eq.6）
- `Z'_I = f_cp(Z_I)`，`Z'_T = f_cp(Z_T)`
- **图和文进同一个网络、共享权重**。

### 5. 相似度与损失（Eq.7-9，未改）
- `s = Z'_I · (Z'_T)^T`
- 缩放余弦 + 双向 InfoNCE 对称损失
- **损失函数层面无创新，跟 CLIP 一样。**

### 6. 神经元分配
- 每节点分 `⌊M/N⌋` 或 `⌊M/N⌋+1` 个神经元（M 为该层维度）
- 作者在 Discussion 自己承认这是局限：**用现成策略、所有神经元同等对待**

### 7. 训练细节
| 项 | 值 |
|:--|:--|
| 初始化 | 预训练 CLIP 权重 |
| 数据 | MIMIC-CXR |
| 可训练部分 | 图像编码器 + CP 网络（**文本编码器冻结**） |
| LR | 1e−8（CLIP 部分）/ 1e−3（CP 网络） |
| epochs / batch | 10 / 128 |
| 优化器 | AdamW + cosine |
| 核心比 p | 0.1~1.0，步长 0.1 搜索 |

## 常见误读（🔴 重要，先看这里）

2026-11-10 晚拿到原文 PDF 后，明确纠正了此前流传的三处错误说法：

| ❌ 错误说法 | ✅ 原文实际 |
|:--|:--|
| 图像拆核心/外围、文本拆核心/外围，两条并行支路 | **图文都进同一个共享权重 CP 网络**，没有"拆输入" |
| 核心图对核心文、外围图对外围文，交叉的不对 | 没有这种配对，相似度就是整体 `Z'_I · Z'_T^T` |
| 外围那条乘 λ（外围权重） | **没有 λ**，超参是**核心比 p**（控制核心节点占比） |

**"拆结构"的真相：拆的是网络内部的连接结构（MLP 全连接 → CP 图），不是拆输入。**

> 教训：上午的「念图版」讲法（图拆核心/外围 + λ）是**基于二手描述的推测**，晚上核对原文后被推翻。

## 可借鉴的点
1. **"只改结构、不改损失"** 的成本最低 —— 对应组会归纳的创新路径第 2 类"改目标函数/拆结构"。
2. **核心比 p 是一个可以直接接手的接口**：全局固定 → 可以改成动态 → 见 [[06-创新点池]] I1。
3. **结构化稀疏 vs 随机稀疏**：A⊙W 的写法很轻量，任何 MLP 都能套，通用性强。
4. **p=1 退化为完全图** 这个设计让它可以"向上兼容"普通 CLIP，是很聪明的工程性选择。
